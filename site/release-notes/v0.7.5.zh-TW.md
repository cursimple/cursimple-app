# 0.7.5 · 測試版

本次以測試版發佈，版本號為 0.7.5。0.7.4 也屬於測試版，目前尚無正式版。應用內開啓「測試版更新」後可接收本次更新；截圖使用演示資料。

## 把今日安排看清楚

今天的日課表新增概覽卡片，顯示當前課程、下一節課和上下課倒計時。點開就是全天課程時間線，時間衝突也會單獨提醒。

![今日課程時間線 · 演示資料](../assets/shots/agenda.png)

## 課表裝進桌面日曆

新增「課程日曆」小工具，可以切換周課表和月曆，查看課程、考試、事務與休息日。前後翻頁、回到本週，以及點日期打開對應課表都更方便。

![課程日曆小工具 · 周課表示例](../assets/shots/calendar-widget.png)

## 待完成的事隨時看

新增「待完成」小工具，把啓用元件里的作業、考試等未完成內容放到桌面。開始時間、截止時間和臨近截止的狀態一起顯示，點開可回到來源元件。

![待完成小工具 · 演示資料](../assets/shots/pending-widget.png)

## 外掛和元件更好找

外掛與元件都有清楚的「已安裝／市場」入口，搜尋能查名稱、簡介、學校別名和來源。卡片直接顯示版本、來源與更新狀態，手動重新整理和安裝前會重新檢查版本。

![外掛市場、來源和安裝入口](../assets/shots/plugin-market.png)

## 自己的儲存庫也能用

外掛來源和元件來源分別改成可增刪的清單，預設公有儲存庫可以與額外來源一起用。同頁登入 GitHub 令牌後，可以讀取有權限的私有儲存庫；移除來源需要再次確認。

![來源清單與 GitHub 帳號入口](../assets/shots/market-sources.png)

## 安裝資訊先看重點

詳情頁收起分類切換，把簡介、版本和儲存庫資訊排清楚。安裝先看簡介、來源和實際包大小，權限與技術資訊按需展開；彈窗大小固定，只在內部滾動，大包提供真實下載進度。

![安裝摘要，權限與技術資訊預設折疊](../assets/shots/plugin-install.png)

## 筆記內容一搜就到

備忘錄右上角新增搜尋，支援標題、完整正文和課程資訊，其他筆記本和已完成筆記也能找到。清空或關閉後回到原來的篩選，搜尋框、按鈕與確認框統一復用應用現有樣式。

![備忘錄全文搜尋 · 演示資料](../assets/shots/memo-search.png)

## 元件帶上自己的頁面

新增擴展元件接口，支援元件自帶登入、設定、月曆和清單頁面。課簡可承接新內容通知、截止提醒與課表事務，並把未完成內容顯示在桌面。下圖以本地雨課堂 v1.2.0 為例；元件需獨立安裝，本次應用發佈不包含該元件包。

![雨課堂元件清單 · 本地 v1.2.0，演示資料](../assets/shots/yuketang.png)

## 明天鬧鐘交給系統時鐘

鬧鐘頁新增「寫入系統時鐘」，把明天可寫入的鬧鐘交給手機時鐘，同一分鐘的項目會合併。全部送出後可選擇靜音課簡明天的鬧鐘，清單里也能取消靜音。

![系統時鐘寫入確認與靜音選項](../assets/shots/system-clock.png)

## 響鈴界面重新整理

鬧鐘響起時，時間、日期和課程資訊更清楚，配色跟隨應用主題。底部滑動關閉減少誤觸，也修正了滑到底仍無法關閉的問題。

![鬧鐘響鈴界面 · 演示資料](../assets/shots/alarm-ringing.png)

## 假日、無課與提醒

- 假日鬧鐘預設按放假規則跳過，單個鬧鐘可以選擇「節假日也響」；手動靜音日期仍優先，並能在清單里取消。
- 假期前晚可查看第二天被跳過的鬧鐘；被跳過的鬧鐘不再提前發送響鈴預告。
- 無課、下課、假日和沒有任務時，今日概覽及小工具多了一些輕鬆的提示。同一天同類提示保持穩定，第二天再換一句。
- 上課提醒新增診斷入口，補充部分手機的橫幅、鎖屏和後台彈出引導；滑動收起提醒後，通知欄里的內容仍會保留。

## 排版與細節

- 頂部圖標、搜尋框、帶框按鈕、儲存庫資訊框和刪除確認框改用共用控件，尺寸與文字更統一。
- 課程日曆和待完成小工具單獨分類；事務詳情較長時可以在容器里滾動。
- 預設周數統一為 20 周，仍可調整為更長學期；周次切換和部分小工具箭頭也做了排版修整。
- 公有來源與額外來源分別載入，一個來源不可用時不會遮住其他來源的結果。GitHub 令牌加密保存在當前手機，不隨備份遷移。

## 修復

- 補齊 Android 7 的鎖屏提醒與通知兼容處理，修正語言切換後的狀態文字和月曆標題。

- 修復小工具在編輯或刪除導入課程後重復顯示、舊課程重新出現的問題。
- 修復移入課程繞過假日或靜音規則、跨周調課通知顯示錯誤地點的問題。
- 修復元件頁面滑動時誤打開側邊欄，以及長正文滾動受影響的問題。
- 修復市場重新整理和安裝時沿用舊版本資訊的問題，並避免已知較新版本被舊清單覆蓋。

## 使用說明

預設 GitHub 登入使用令牌；雨課堂 v1.2.0 演示元件尚未發佈到公有市場，需另行導入元件包。系統時鐘寫入後請打開手機時鐘核對，之後的調課或假日變化不會自動修改已寫入的鬧鐘。待完成小工具需要有啓用中的擴展元件，後台同步仍受系統與網路影響。
