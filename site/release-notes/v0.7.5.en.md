# 0.7.5 · Beta

Version 0.7.5 is a beta release. Version 0.7.4 is also a beta; there is no stable release yet. Enable beta updates in the app to receive this version. Screenshots use demo data.

## See today's schedule clearly

Today's daily timetable now includes an overview of your current class, next class and countdowns to the start and end of class. Open it for the full day's timeline, with separate notices for scheduling conflicts.

![Today's course timeline · Demo data](../assets/shots/agenda.png)

## Your timetable in a calendar widget

The new Course Calendar widget switches between a weekly timetable and monthly calendar, showing classes, exams, events and days off. Move between weeks, return to the current week or tap a date to open its timetable.

![Course Calendar widget · Demo weekly timetable](../assets/shots/calendar-widget.png)

## Keep pending tasks in view

The new Pending Tasks widget shows unfinished homework, exams and other items from enabled components. Start times, deadlines and approaching deadlines appear together. Tap an item to open its source component.

![Pending Tasks widget · Demo data](../assets/shots/pending-widget.png)

## Find plugins and components faster

Plugins and components each have clear Installed and Market views. Search by name, description, university alias or source. Cards show the version, source and update status. Manual refresh and installation both check the version again.

![Plugin market, sources and installation](../assets/shots/plugin-market.png)

## Add your own repositories

Manage plugin and component sources separately. Use the default public repository alongside additional sources. Add a GitHub token on the same page to read private repositories you have access to. Removing a source requires confirmation.

![Source list and GitHub account entry](../assets/shots/market-sources.png)

## Clear details before installation

The details page focuses on the description, version and repository. Installation shows the description, source and actual package size first; expand permissions and technical details when needed. Dialogs scroll within a fixed size, and large packages show real download progress.

![Installation summary with permissions and technical details collapsed](../assets/shots/plugin-install.png)

## Search the whole note

Search from the top right of Notes to find titles, full text and course details, including other notebooks and completed notes. Clear or close search to restore your previous filters. Search fields, buttons and confirmation dialogs now use the app's shared styles.

![Full-text note search · Demo data](../assets/shots/memo-search.png)

## Components bring their own pages

New extension interfaces let components provide their own sign-in, settings, monthly calendar and list pages. CurSimple handles new-content notifications, deadline reminders and timetable events, and displays unfinished items on the home screen. The screenshot uses the local Rain Classroom v1.2.0 component. Components install separately; this app release does not include that component package.

![Rain Classroom component · Local v1.2.0, demo data](../assets/shots/yuketang.png)

## Tomorrow's alarms in your system clock

The alarm page can now send tomorrow's eligible alarms to your phone's clock app. Items at the same minute are merged. After all alarms have been sent, you can mute tomorrow's CurSimple alarms and later unmute them from the list.

![System clock export confirmation and mute option](../assets/shots/system-clock.png)

## A clearer alarm screen

The ringing screen shows the time, date and course more clearly, with colors that follow your theme. Slide at the bottom to dismiss or snooze. An issue where sliding all the way failed to dismiss the alarm has also been fixed.

![Alarm screen · Demo data](../assets/shots/alarm-ringing.png)

## Holidays, free time and reminders

- Holiday alarms follow holiday rules by default. Individual alarms can still ring on holidays; manually muted dates take priority and can be unmuted from the list.
- On the evening before a holiday, you can review tomorrow's skipped alarms. Skipped alarms no longer send advance ringing notices.
- The daily overview and widgets have new messages for free periods, finished classes, holidays and empty task lists. Messages remain consistent through the day and change the next day.
- Class reminders include a diagnostic entry and more guidance for banners, lock-screen notifications and background pop-ups on some phones. Swiping away a floating reminder keeps its notification in the notification shade.

## Layout and details

- Top-bar icons, search fields, outlined buttons, repository panels and deletion dialogs use shared controls for consistent sizes and text.
- Course Calendar and Pending Tasks widgets have separate categories. Long event details scroll within their container.
- The default semester length is 20 weeks, with longer semesters still supported. Week selection and some widget arrows have layout improvements.
- Public and additional sources load separately, so one unavailable source does not hide other results. GitHub tokens are encrypted on the current phone and excluded from backups.

## Fixes

- Improved lock-screen reminders and notifications on Android 7, and corrected status text and calendar headings after switching languages.
- Fixed duplicate widget entries and deleted courses reappearing after editing imported courses.
- Fixed moved classes bypassing holiday or mute rules, and incorrect locations in notifications for classes moved across weeks.
- Fixed component-page swipes opening the sidebar accidentally and interference with scrolling long content.
- Fixed stale version information during market refresh and installation, and prevented older catalogs from replacing a known newer version.

## Usage notes

GitHub sign-in uses a token by default. The Rain Classroom v1.2.0 demo component is not available in the public market and must be imported separately. Check exported alarms in your phone's clock app: later timetable or holiday changes do not update those alarms automatically. The Pending Tasks widget requires enabled extension components. Background synchronization depends on system scheduling and connectivity.
