# v0.7.1-beta.4 更新内容

## 课表格子排得更紧凑了

长课名以前被硬切成「计算机组成与系」，现在按字数自动缩字号，多塞得下一到两行：

- 5 字以内不动，7 字小一档，9 字小两档，10 字以上小三档
- 缩到 9sp 就打住，再小笔画糊成一团
- 课名行距压到比字号只高 1sp——课名常要折三四行，行距是最占地方的一项

「非本周」「考试」这类标记字号和行距一并压小。它们只是注解，以前白占一整行，把本来就长的课名又挤掉一行。

## 课表底部留白

滚到最后一节时贴着容器边缘，看起来像被切掉了。现在留一段余量，一眼能看出是「到底了」而不是「还有没显示完的」。平铺模式不加留白，那种模式本来就把全部节次塞进一屏。
