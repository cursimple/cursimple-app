# 0.7.11 · Beta

Version 0.7.11 builds on 0.7.10 with courses that use real clock times, events repeated on chosen weeks, sidebar customization and a bottom bar layout, plus reworked widgets and a tidier manage list. Enable beta updates to receive it.

## Courses can take a time directly

Adding, quick-adding and editing a course now switches between "By period" and "By time". With "By time" you pick a start and end time, and the timetable places the card at that time. Single-class reminders, first-class alarms, pre-class silencing, course details, calendar export and home screen widgets all use it too.

Classes that do not fall on a standard period are no longer squeezed back into one. A 12:10–13:30 lunch class, for example, is inserted between periods 3–4 and 5–6 on its own band, with the real times shown on the left.

![Adding a course by time](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.11/docs/release-notes/images/v0.7.11/course-clock.en.png)

![The timetable places classes at their real time](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.11/docs/release-notes/images/v0.7.11/grid.en.png)

Courses placed by time cannot be dragged; open the edit form to change the time.

## Events repeat on the weeks you pick

The weekly repeat switch becomes three choices: once, weekly, or picked weeks. With picked weeks you tap any weeks in the grid and the event lands on the matching weekday of each. Details and the list show the dates, for example "2 weeks: 10/14, 10/28".

![Picking the weeks an event repeats on](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.11/docs/release-notes/images/v0.7.11/event-weeks.en.png)

![Tap any weeks in the grid](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.11/docs/release-notes/images/v0.7.11/event-weeks-matrix.en.png)

## Arrange the sidebar yourself

Settings now includes Sidebar: drag items to reorder them and switch each one off. A hidden item is not gone — it moves into "More" at the bottom of the sidebar and stays reachable. The timetable and settings are always shown, and the four shortcut buttons can be turned off as a group. The sidebar shows up to three components, with the rest behind "View all".

![Reordering and hiding sidebar items](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.11/docs/release-notes/images/v0.7.11/sidebar.en.png)

## Put everyday pages on the bottom bar

With the Layout component installed, navigation can move from the sidebar to a bottom bar, by default Timetable · Notes · Components · Me. Timetable stays first and Me stays last, with up to three entries between them. Pages left off the bar, and the four shortcuts, are collected on the Me page, which also carries the update dot. Switch back from the component settings or from Settings → Sidebar; disabling or removing the component returns to the sidebar automatically.

## Today's schedule includes events

The Daily classes widget is now Today's schedule: events and classes share one time-ordered column, events carry an "Event" tag and are marked while in progress. The course calendar widget marks days that have events. Settings → Home screen widgets gains "Show events on widgets", on by default.

## The manage list, reorganized

The manage list switches between Courses and Events at the top, and the button in the corner follows the current tab. Cards show more per screen; edit, restore and delete move into a ⋮ menu, and the note about editing plugin courses appears once. Deleted courses can be removed for good: they are no longer restorable and the next sync will not bring them back.

## More improvements

- The countdown to the start and end of class shows seconds and uses tabular digits so it does not jitter; other content refreshes on the minute.
- Home screen tasks open a read-only detail view first, with a pencil to edit; the floating window keeps a fixed height.
- Notes can insert several images at once, in the order you pick them, undone together.
- Whether locations are prefixed with @ is a setting, on by default; a slightly long location shrinks instead of losing its last character.
- Settings sub-pages move their title and back button into the app bar, and full-screen pages animate in and out.
- The Today's schedule and course calendar widgets open the timetable for the day they show.

## Fixes and stability

- Closing a home screen window (task editor, course details) no longer flickers, slides or zooms.
- Launching the app no longer redraws every widget, so home screen cards flicker less; widgets refresh only when the time zone, notes and similar actually change.
- Widgets update their state before, at the start of, and at the end of an event.
- Teacher and location fields no longer open a dropdown while you type; tapping the field only moves the caret, while the arrow lists saved values.
- Notes sharing and import screens follow a language change.

## Component capabilities

- The component API is now 12: a component can declare layouts it provides, drawn natively by CurSimple, and its page can query or apply the current layout. Requests that break the rules are rejected with a message and change nothing. Components on API 11 and below keep working.
- The protocol is documented in `docs/plugin-system.md`, which now also covers API 10 and 11.

## Companion components and plugins

- Layout component v1.0.0 switches navigation to a bottom bar and lets you choose what it holds; it needs CurSimple 0.7.11 or newer.
- The YuKeTang notice component v1.3.8 and the multi-platform notification component v1.2.8 are published separately.
