# v0.7.1-beta.1 更新内容

## 从教务系统导课，不用再自己找插件

- 右上角「＋」新增「从教务系统导课」：搜学校名 → 装插件 → 登录导课，一页走完
- 注册表支持给插件声明学校别名，中文全称、简称、拼音都能搜到（仓库叫 `bit-schedule`，搜「北理工」也能出来）
- 登录教务系统的网页会话就在这一页弹出，装完插件不用再绕去插件页
- **插件装好后默认就是启用的**，不必再回插件页手动打开
- 学校还没有插件时会直说，并给出手动加课的入口，不再只丢一句「没找到」

## 课程详情弹窗重做

- 信息排得更紧凑：名称与取值同行，同一格有两门课时也放得下
- 底部操作改成等宽图标按钮，不会再因为按钮多而每行只剩一个
- 同位置多门课的切换标签改成换行摆放，不再被截断
- 新增「编辑」：上课时间、周次、地点、教师等直接在详情里改，不用退出去重开表单

## 插件同步的课程也能改了

- 课程详情和「全部课程」里，插件同步来的课都可以编辑
- 改完会转成手动课程，下次同步不会把你的修改冲掉
- 改过的课随时可以「还原」回插件下发的那一份

## 长按课程直接出操作

- 长按不再只有多选：编辑、移动、设提醒、多选、删除都摆出来了
- 新增「移动」：选星期和起始节次把课挪到任意位置，允许和别的课重叠，重叠的课名会提示出来
- 移动和删除都带二次确认，防手误

## 双击日期栏设置这一天

- 周视图的日期列、日视图的日期栏都可以双击
- 三个选项：跟随节假日日历 / 这一天照常上课（取消节日）/ 这一天全天停课（可自己命名）
- 调休、院系单独放假、临时停课都能就地改，不必去设置里翻

## 新手引导会带你逛一遍

- 引导不再只停在主页，讲到导课、全部课程、插件时会真的切过去，看完退回课表
- 设置里新增「重看新手引导」，随时可以再走一遍

## 其他

- 学期管理的开学日期改用自绘月历，不再被系统日历的固定高度挤得叠在一起
- 新建课程时周次不再预填 1-16，避免直接保存成错误周次
