# 0.8.2-pre.2 · 預發布測試版

0.8.2-pre.2 為 pre 分支測試版本，重點最佳化擁擠日課表版面、橫屏與平板體驗、小工具和匯入安全。本版本僅供測試體驗，不推送至正式更新源。

## 擁擠日課表版面
- 每天最多 2 欄：兩門課時間交叉時左右並排，不交叉的課上下排列在同一欄。
- 同一時段 3 門以上時，保留離「現在」最近的兩門，其餘收進右下角的「⋯」，點開可查看全部，並顯示時段、教室、老師以及「正在上課 / N 分鐘後開始 / 已結束」。
- 螢幕放不下時，課最少的日子自動退回單欄，避免課程卡片被壓成一字一行的長條；平板與橫屏寬度足夠時每天最多 3 欄。
- 有折疊內容的日期表頭顯示小圓點，今天的欄加淡色底；教室號在窄卡片裡優先在連字號處換行。
- 左側節次欄進一步收窄，給課表更多空間。

## 橫屏、小工具與匯入
- 修復橫屏崩潰與無法捲動，更新日誌圖文排版更寬鬆。
- 備忘錄小工具可顯示更多項目並支援捲動；新增小工具透明度、模糊與深色適配、課程膠囊小工具。
- 新增 ICS、WakeUp、小愛課表匯入，課表時間線指示、晚間簡報、換教室與考試提醒（預設關閉）。

## 安全加固
- 加固匯入、下載、檔案提供器、備份規則與外掛套件解析，限制大小與權限。
- 更新建置工具鏈相依，替換內建舊 jQuery，加入相依安全掃描工作流程。
