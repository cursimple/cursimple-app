# 0.8.2-pre.1 · 预发布测试版

0.8.2-pre.1 为 pre 分支特性测试版本，带来了周视图横滑手势切周、课表个性化风格配色与单课调色、智能系统日历增量同步与一键清理、第三方导入整合卡片等多项全新体验与优化。本版本仅供测试体验，不推送至正式更新源。

## 周课表横滑手势切周
- 课表网格区域现已支持左右横滑手势切周，翻看前后周课表更自然顺手。
- 伴随平滑横向位移与淡入淡出动画，到达首周与末周时具备智能边界阻尼。

## 课表个性化配色盘与单课专属调色
- 新增 5 种预设风格色盘：默认清新（Fresh）、莫兰迪灰调（Morandi）、马卡龙甜心（Macaron）、多巴胺活力（Vibrant）、复古原木（Vintage）。
- 课程详情中支持为任意单门课程自定义专属色块，并支持一键恢复为默认。

## 智能系统日历同步
- 导出系统日历时为日程附加专属唯一标识（UID）。
- 再次同步时支持智能增量 Diff（自动清理已删除/调走课程、更新时间地点变更、写入新课程）。
- 新增彻底一键清除已写入日历日程的功能，避免残留多余日程。

## 第三方导入整合与界面规范统一
- 在导入导出页面中新增「第三方导入」专属卡片，收纳 WakeUp 导入、小爱课表导入与通用 ICS 导入。
- 统一规范弹窗与输入框设计风格，边框视觉层次与交互更加清晰。
- 适配平板与折叠屏双栏布局、实时时间线与小组件交互增强。
