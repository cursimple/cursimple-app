# v0.7.0-beta.8 更新内容

## 更新与下载更快了

- 记住上次走通的镜像并持久化：更新检查、更新公告、插件市场、节假日数据第二次起只发一个请求，秒回
- 镜像失效时自动重新竞速，无需手动处理
- 安装包下载的测速结果缓存 24 小时，不再每次全量重测

## 镜像清单大维护

- 逐个实测了 40+ 个镜像：清掉已失联的，修正 xget 的路径错误
- 新增实测可用的镜像：edgeone.gh-proxy.com（三种用途全通）、cdn.jsdmirror.com 等境内 CDN（实测 0.1-0.4 秒，最快）
- API 请求与文件下载分流，不再让不代理 API 的镜像白占竞速名额

## 课表显示

- 地点里的学校名不再显示在课表格子里（如「东13-306长江大学」只显示「东13-306」）；课程详情、编辑、导出仍是完整地点

## 修复

- 启动时更新弹窗与开学日期提醒不再叠着出现
