# v0.7.1-beta.6 更新内容

## 修复：插件清单一直是旧的，搜学校搜不到

插件清单走的是 GitHub 分支路径，各家代理和 CDN 会按整条 URL 缓存十几个小时，而且是**每个边缘节点各缓存各的**——源站早就更新了，你所在地区的节点仍可能发旧文件，谁也没法把全世界的节点挨个清一遍。

现在请求上带一个按 5 分钟取整的参数，等于把中间缓存的上限压到 5 分钟；这个参数会一路带到各家镜像，按路径改写的那几家（jsDelivr 等）也不会把它丢掉。同时请求带上 no-cache 头，肯听的代理会直接回源。

清单只有几百字节，这点重复请求可以忽略。

搜「长江大学」「长大」「cjdx」现在都能找到对应插件。
