# 1.0.0 · 正式版

課簡 1.0.0 將課表、事務、教務匯入、筆記、小工具和資料遷移整理成更完整的學習工具。這次更新改善擁擠課表的排版，讓教務匯入更清楚，加入完整的本機備份流程，也重新整理了導覽與互動細節。

## 從教務系統匯入課表

- 在新增選單開啟「從教務系統匯入」，可以用學校名稱、拼音或首字母搜尋。
- 已安裝外掛的學校會優先顯示「外掛匯入」。沒有外掛的學校使用「通用匯入」，有外掛的學校也可以改用通用匯入。
- 學校列表提供字母索引、連續捲動和網址入口。名單沒有你的學校時，可以輸入校外可訪問的教務系統網址。
- 通用匯入只有在登入、進入真實課表頁面並點擊「上傳課表」後才會讀取，不會開啟頁面就自動擷取。
- 解析失敗會留在匯入頁並說明原因。資料不完整時整次匯入會取消，不會保存殘缺課表。
- 支援常見的網格、轉置表、長表、卡片和位置排版，以及單雙週、區間週次、中文節次和常見欄位格式。
- 成功匯入後優先使用教務系統提供的作息時間。沒有可靠開學日期時保留提醒，從最早有課的週次開始預覽，不會自行填入日期。

## 課表與事務

- 重疊課程依實際時間排版。時間不同的課分開排列，相同課程合併到同一張卡片並顯示數量，三門以上使用展開入口。
- 展開後會區分本週上課和其他週課程，並顯示具體週次。
- 事務使用與課程相同的時間排版。兩個重疊事務左右排列，更多事務才使用展開入口。課程和事務重疊時，課程優先顯示。
- 日期標題顯示當天事務數量。點擊有事務的日期查看事務，長按日期開啟假日、調課和停課設定。
- 管理列表支援課程與事務分頁、長按多選、批量操作、事務排序和來源篩選。沒有外掛事務時不顯示來源篩選。
- 刪除的課程會進入回收站。回收站可以查看完整課程資訊、恢復和清空，恢復與清空都需要二次確認。
- 課程詳情使用置中的詳情視窗，時間、教室、老師與週次集中顯示。同位置的多門課可以用箭頭或左右滑動切換。
- 編輯課程和事務時保存操作保持可見，星期與日期支援多選，節次優先使用目前作息表中的名稱。

## 課程結束提醒

- 課程結束前兩週開始提醒，倒數第二週顯示 `2`，最後一週顯示 `1`。
- 課程保留原本顏色，只使用以課程顏色為基礎的柔和發光邊框。
- 課程詳情、課表圖例和小工具使用同一套提醒狀態。
- 設定位置為「設定 → 顯示 → 課程結束提醒」，預設開啟。

## 學期統計

- 統計包括總課量、教學時間、早八、晚間課、課程最多週、課程最多日和課程排行。
- 每週長條圖上直接顯示數字，點擊或長按可以查看該週課程。
- 課程最多週、課程最多日、早八和晚間課卡片都可以展開查看完整課程列表。

## 分享、筆記與本機備份

- 分享碼使用更緊湊的格式，同時保留舊分享碼的讀取能力。
- 分享資料可以包含作息時間、課表名稱和來源顯示資訊，匯入時可以選擇套用分享方作息。
- 筆記支援圖片、待辦、清單和課程關聯，圖片會保留在本機筆記資料中。
- 設定新增獨立的「本機備份」入口，位於 WebDAV 上方，進入後直接看到「匯入」和「匯出」。
- 匯出支援全部資料或選擇分類，產生 ZIP 壓縮檔。分類包括課表、課程、事務、筆記、備忘錄、小工具、提醒、外掛記錄等。
- 匯入只顯示新增、修改和刪除的內容，也會顯示備忘錄圖片變化。沒有變化的項目不會列出，備份沒有包含的分類會保留在裝置上。
- 確認後才會寫入資料。恢復過程失敗時會嘗試回復匯入前快照，避免部分恢復造成資料缺失。

## 小工具與提醒

- 今日、週課表、下一節課、提醒和課程膠囊小工具會跟隨應用程式主題。
- 小工具預設顯示事務，也可以在小工具設定中關閉。
- 課程結束提醒使用數字角標和柔和邊框，圖例會說明 `2` 和 `1` 的含義。
- 今日課表標題可以開啟應用程式內日期選擇器，直接跳轉到指定日期。
- 小工具卡片之間保留間距，不會黏成一整塊。
- 開發者頁面新增鬧鐘測試，方便檢查應用程式內鬧鐘鏈路。

## 介面與互動

- 課表樣式和顯示設定頁保留頂部即時課表預覽，調整選項時可以立即看到變化。
- 側邊欄快捷入口可以切換明暗模式、主題色、課表樣式、課表背景和小工具背景。
- 課程與事務分頁使用平滑的橫向切換動畫，搜尋、篩選和捲動狀態會保持。
- 首次使用流程改為可跳過的圖文介紹，權限頁會先列出各項權限和目前狀態。
- 空狀態、匯入提示和占位文案重新整理，減少不必要的裝飾符號。
- 課程、事務、外掛、備份和匯入頁面統一按鈕、彈窗、圖示、圓角與深淺色適配。

## 穩定性與資料安全

- 增強舊教務系統 WebView 相容性，減少首頁空白或殘缺頁面的情況。
- 連線失敗、登入過期、重新整理逾時和空結果會分開提示，重新整理失敗時保留上次成功資料。
- 外掛主頁和業務內容由外掛自行提供，主應用只提供通用容器、登入、儲存和生命週期能力。
- 外掛、元件與主體更新記錄分開維護，學校外掛的專屬更新不會混入課簡主體公告。
- 匯入、下載、ZIP 備份和外掛套件解析增加格式、大小、路徑與權限檢查。
- 更新應用程式會保留本機資料。不同簽章的安裝包無法直接覆蓋，跨簽章遷移時請先匯出本機 ZIP，再安裝新包並恢復資料。
