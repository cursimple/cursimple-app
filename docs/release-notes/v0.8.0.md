# 0.8.0 · 测试版

0.8.0 是一次比较大的更新：可以把几个学期合成一个，课程库能看清一门课在不同周的安排，课程名、老师、地点都能按周设置，撞课一键分流；导出的锁屏壁纸改成真正铺满的 9:16，还能自己挑图里显示什么、导出哪几天。另外事务改为按学期保存，今日概览、上课提醒和设置页也都有改进。应用内开启「测试版更新」后可接收本次更新。

## 学期合并：辅修、多校区、跨年课表合到一起

学期管理页新增「课表合并」。勾选两个及以上学期，课程会对齐到一个新的独立学期里。原来的学期和数据都不动，不满意直接删掉合并出来的学期，就回到原样。

- **两种对齐方式**：「按真实日期对齐」适合同一学期的主修 + 辅修/实验课，按开学日期差顺延周次；「按教学周次对齐」适合复用往期或跨年课表，第 1 周直接对第 1 周。
- **合并前先看效果**：每个学期旁边标出「基准周 / 顺延 +N 周 / 往年学期（-N 周）/ 跨学年」，也可以指定用哪个学期的开学日期作为起点。
- **异常情况会提醒**：检测到往年学期，或所选学期开学时间相差太大时，会建议改用「按教学周次对齐」，免得课程被推到负数周或很靠后的周次。
- 合并后的课程详情多一行「来源学期」，看得出这门课原本属于哪个学期。

![勾选两个学期后确认合并](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.8.0/docs/release-notes/images/v0.8.0/term-merge.png)

## 课程库：一门课的不同安排一眼看清

一门课如果某几周换了教室、换了老师或者改了名字，或者同一门课一周上好几次，课程库里会把它们合成一张卡片，标题旁标出「N 种安排」。

- 点「展开各周安排」，每种安排单独一行：哪几周、什么时间、在哪、谁上。
- 第一行标着「主安排」，其余各行里和它不同的地方会用颜色标出来，比如 5-8 周换到了实验楼、第 12 周换了老师。
- 点任意一行直接进入编辑；移动、闹钟、删除这些操作在每行右侧的菜单里。
- 搜索也能搜到按周设置的地点、老师和名字。

![课程库里展开一门课的各周安排](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.8.0/docs/release-notes/images/v0.8.0/library-variants.png)

## 按周设置课程名、老师、地点

课程名也能按周单独设置了。编辑课程时点课程名右侧的日历图标，打开「各周课程名称」，给不同周次填不同的名字；设置过的图标会高亮，并显示「已为 N 周单独设置名称」。

设置各周的课程名、老师、地点时，弹窗改成了同一套用法：先选周，再填值。

- 周次网格上方可以筛选「全部 / 已设置 / 未设置」，每一格直接显示这一周现在的值。
- 可以逐个点选，也可以横向滑动连选；「全选 / 单周 / 双周 / 清空」只作用于当前看到的周。
- 下方「各周情况」按取值分组列出周次，点一组就选中那几周。
- 选中的几周取值不同时会提示「这几周不一样，填写后统一修改」，不想改了点「恢复默认」。

![各周课程名称弹窗](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.8.0/docs/release-notes/images/v0.8.0/week-titles.png)

## 撞课快捷分流

两门课的周次和节次重叠时，课程详情里会出现「撞课快捷分流」：

- **单双周分流**：当前这门课上单周，另一门上双周。
- **前后学期分流**：以两门课周次的中点为界，一门上前半段，一门上后半段。

点一下两门课同时保存，不用再分别去改周次。

![课程详情里的撞课快捷分流](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.8.0/docs/release-notes/images/v0.8.0/conflict-split.png)

## 加课、考试、事务同一个入口

「添加课程」和在课表空白处快速添加时，顶部多了「课程 / 考试 / 事务」切换。选「考试」就是添加考试；选「事务」会换成事务表单，可以填日期、起止时间、地点、备注、重复方式和颜色。

在课表某个位置添加事务时，会自动带上那个位置的日期和节次。

![添加时顶部的课程、考试、事务切换](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.8.0/docs/release-notes/images/v0.8.0/add-entry.png)

## 事务跟着学期走

事务改为按学期保存。切换学期后，课表上的事务也跟着切换，上个学期的事务不会再混进来。已有的事务会在第一次启动时自动归到当前学期，不会丢。

## 课表图片：铺满的锁屏壁纸，内容和天数都能挑

- **真正铺满的 9:16 壁纸**：导出时选「锁屏壁纸 9:16」，课表按竖屏重新排版，从状态栏下面一直铺到底部手势条上方，字号按竖屏放大，课程名写全不省略，可以直接设成锁屏。
- **图片里显示什么自己挑**：导出弹窗右上角的设置按钮里，可以分别开关课程、考试、事务，上课周数、地点、老师，以及节次时间和日期。默认只显示课程名和周数，事务、地点和老师需要时再打开。选择会记住，下次导出沿用。
- **导出哪几天也能挑**：周一到周日任意多选，可以只导出一天，也可以只导出工作日。选「单周」时导出的是那一周的这几天，选「全部周」时就是每周重复的这几天。没课的日子照样保留一列。
- **事务按实际时间摆放**：打开事务后，事务放进对应的节次里，不在上课时间内的会单独插一行。
- **保存到本地**：Android 10 及以上存到「图片/CurSimple」，更低版本用系统的新建文件选择器。文件名带学期、周次和壁纸标记，方便查找。
- 预览可以全屏查看、双指缩放，确认没问题再分享或保存。

## 今日概览

- 调休补课的日子会提示「今日按 X 课表上课」，不再只看今天是星期几。
- 新增「今日自习与空闲时段」，按上午、下午、晚上列出没课的时间和对应节次。

## 上课提醒

- 打开「上课提醒」开关时直接申请通知权限，不用再去设置里找。
- 预览提醒前会先检查权限：没授权就弹出系统授权框；通知被系统关掉或缺少悬浮窗权限时，会说明原因并直接跳到对应的设置页。
- 系统把横幅调低、预览只进了通知栏时，会提示「没看到横幅？」并给出打开入口。
- 提醒标题用这一周的课程名，和课表上显示的一致。

## 更多改进

- 设置页的子页面切换带左右滑动过渡，卡片、开关行和分隔线的配色统一，能点进去的项右侧都有箭头。
- 底栏布局可以选按钮大小（小 / 中 / 大）。
- 课表和事务一屏放不下、或者课程名会被挤成一竖列时，自动改为上下滚动，并在顶部提示几秒；删掉多余的课程或事务后自动恢复平铺，设置里的「纵向排布」也会显示当前是否在临时滚动。课多的日子变宽时，其他天至少保留两个字的宽度。
- 桌面「今日安排」小组件新增「回今天」按钮。
- 系统日历导出面板重新排版：账号带颜色圆点和勾选，导出时显示进度，有导出记录时才出现「撤销」。
- 笔记和课程库的空状态改成居中卡片，文字更短；勾选、切换标签和选周都加了触感反馈。
- 在课程库的「课程」页点新增，也能直接添加事务，并自动切到「事务」页。
- 下载和插件安装的镜像补充了更多备用线路，弱网下更容易连上。

## 网盘同步

WebDAV 不再预填任何网盘地址，地址栏默认留空，填你自己的网盘服务商提供的目录地址即可。

## 修复

- 合并学期后，课程详情、课表和提醒读到的各周课程名保持一致。
- 系统日历导出和「撤销上次写入」的状态判断更准确。
- 开启系统「减少动画」后，上课提醒开关的展开和设置页的切换不再播放动画。
- 课表页的状态提示改用应用内设置的语言，不再跟随系统语言。
