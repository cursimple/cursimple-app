# 0.8.2-pre.3 · 预发布测试版

0.8.2-pre.3 为 pre 分支测试版本，新增共同空闲时间、学期管理与学期统计，并补充课程待办、出勤记录和导入失败诊断。本版本仅供测试体验，不推送至正式更新源。

## 共同空闲时间
- 添加菜单中新增「共同空闲时间」：粘贴同学的分享码，即可对比两人课表，列出每周两人都没课的时段，方便约饭、约小组讨论。数据只在本地计算，不需要服务器。

## 学期管理与统计
- 学期管理页可把已有学期「复制」为新学期，保留课程与时间设置；周次和提醒默认不带过去，提醒可选择保留。
- 旧学期可「归档」，归档后仍可回看和统计，不影响当前学期。
- 新增学期「统计」页：总课时、每周课量、各门课占比与出勤汇总。

## 课程细节
- 课程可添加待办，课表卡片上显示未完成数量。
- 课程可记录出勤（出勤、缺勤、请假），统计页自动汇总。
- 课程表单分区重排，周次选择独立成段；课程外观支持预设与渐变色。

## 导入、备份与设置
- 导入失败时弹出诊断对话框，给出原因、建议和可复制的详情。
- WebDAV 支持每周自动备份，自动备份数量超出后清理最旧的一批。
- 设置页按显示与样式重新分组，分组可折叠；新增时间列宽度设置。
- 备忘录支持插入图片、复制文本。
