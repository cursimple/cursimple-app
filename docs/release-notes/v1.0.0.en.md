# 1.0.0 · Stable release

CurSimple 1.0.0 brings the timetable, events, academic-system import, notes, widgets and data migration into one more complete study companion. This release improves crowded timetable layouts, makes academic imports clearer, adds a full local backup flow and polishes the app's navigation and interaction details.

## Import from your academic system

- Open “Import from your academic system” from the Add menu and search by school name, pinyin or initials.
- Schools with an installed plugin show “Plugin import” first. Schools without a plugin use “General import”, and plugin schools can also fall back to General import.
- The school list has a letter index, continuous scrolling and a direct URL entry. If your school is not listed, enter an academic-system URL that can be reached outside campus.
- General import reads the current page only after you sign in, open the real timetable page and tap “Upload timetable”. It does not capture automatically when a page opens.
- A failed parse stays visible in the import screen and explains whether no timetable was found, no courses were recognised, or some courses are missing a title, week or period. Incomplete data is rejected as a whole.
- Common grid, transposed, long-table, card and position-based layouts are supported, together with single/double weeks, ranges, Chinese period names and common field formats.
- A successful import uses the academic system's period times when available. If no reliable term start date exists, the app keeps the “set a term start date” reminder and previews from the first week with classes instead of inventing a date.

## Timetables and events

- Overlapping courses are laid out by their actual times. Courses with different times use separate lanes, identical courses share one card with a count badge, and three or more courses open from a compact overflow control.
- The expanded course list distinguishes classes in the current week from classes in other weeks and shows the specific weeks.
- Events use the same time layout as courses. Two overlapping events stay side by side, while larger groups use an overflow control. When courses and events overlap, courses stay in front and events remain available behind them.
- A date header shows the number of events on that day. Tap a date with events to open them, or long-press a date to open holiday, adjustment and no-class settings.
- Manage list supports separate course and event tabs, long-press multi-select, batch actions, event reordering and source filters. Source filters are hidden when there are no plugin events.
- Deleted courses go to a recycle bin. The bin shows full course details and supports restore and permanent clearing with confirmation.
- Course details use a centered detail window. Time, room, teacher and weeks are shown together, and courses sharing a slot can be switched with arrows or horizontal swipes.
- Course and event editors keep save actions visible. Weekdays and dates support multiple selection, and periods use names from the active period table.

## Course end warnings

- Warnings begin two weeks before a course ends. The second-to-last week shows a `2` badge and the final week shows `1`.
- Course cards keep their original colours. The border uses a subtle glow based on the course colour instead of darkening the whole card.
- Course details, the timetable legend and widgets use the same warning state.
- The setting is under “Settings → Display → Course end warning” and is enabled by default.

## Term statistics

- Statistics include total sessions, teaching time, early-morning classes, evening classes, busiest week, busiest day and course rankings.
- Weekly bars show their numbers above the bars. Tap or long-press a bar to see the courses in that week.
- The busiest-week, busiest-day, early-morning and evening cards can each expand to show their full course lists.

## Sharing, notes and local backup

- Share codes use a more compact format while remaining compatible with older share codes.
- Shared data can include period times, the timetable name and source display information. Import can optionally apply the shared period table.
- Notes support images, to-dos, checklists and course links. Images remain part of the app's local note data.
- Settings now has a standalone “Local backup” entry above WebDAV. It opens directly to “Import” and “Export”.
- Export supports all data or selected categories and creates a ZIP archive. Categories include timetables, courses, events, notes, memos, widgets, reminders, plugin records and more.
- Import shows only added, modified and removed items, including memo-image changes. Unchanged items are omitted, and categories absent from a partial backup stay on the device.
- Import writes data only after confirmation. If a restore fails, the app attempts to restore the pre-import snapshot to avoid a partial migration.

## Widgets and reminders

- Today, week, next-class, reminder and course-capsule widgets follow the app theme.
- Events are shown by default in widgets and can be disabled in widget settings.
- Course-end warnings use a numeric badge and a soft border. Widget legends explain what `2` and `1` mean.
- The Today widget title opens the app's own date picker so you can jump to a date.
- Widget cards have visible spacing instead of merging into one large block.
- Developer settings include an alarm test for checking the in-app alarm path.

## UI and interaction

- Timetable style and display settings keep a live timetable preview at the top while you edit options.
- The sidebar shortcuts can switch theme mode, theme colour, timetable style, timetable background and widget background.
- Course and event tabs use a smooth horizontal transition while keeping search, filters and scroll state stable.
- First-run setup uses skippable illustrated introduction pages. The permission page lists each permission and its current state before the optional walkthrough.
- Empty states, import messages and placeholder copy have been cleaned up with fewer decorative symbols.
- Courses, events, plugins, backups and imports use a consistent button, dialog, icon, corner-radius and light/dark theme language.

## Stability and data safety

- WebView compatibility was improved for older academic systems that return blank or incomplete home pages.
- Connection failures, expired sessions, refresh timeouts and empty results are reported separately. Failed refreshes keep the last successful data.
- Plugin home pages and their business content are owned by each plugin. The app provides only the generic container, login, storage and lifecycle services.
- Plugin, component and app release notes are maintained separately, so school-specific plugin updates do not enter the CurSimple release notes.
- Import, download, ZIP backup and plugin package parsing now validate formats, sizes, paths and permissions.
- App updates keep local data. Packages signed with a different certificate cannot replace an existing installation. For cross-signing migration, export a local ZIP before installing the new package and restore it afterwards.
