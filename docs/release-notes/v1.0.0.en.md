# 1.0.0 · 正式版

课简 1.0.0 把课表、事务、教务导入、备忘录、小组件、插件主页和本地备份整理成一套完整的学习工具。

## 这次更新

- 事务提醒默认开启，默认提前 20 分钟。设置里可以全局关闭或调整提前时间，单个事务详情里可以单独跟随全局、关闭、准时提醒或选择提前分钟数。
- 课程结束提醒默认关闭，开启后可选择最后一周或最后两周。课表卡片和小组件使用轻量红点、琥珀点和柔和边框，不遮挡课程名称。
- 小组件的上课中状态与结束提醒分开排列，窄尺寸下不再互相遮挡。周课表、今日课表、月历和事务显示保持一致。
- 侧边栏底部的换主题、换背景、调课和检查更新恢复为两列快捷入口，避免窄屏时无故变成四行。
- 学校导入支持拼音索引、连续加载、通用导入和失败原因说明。通用导入只在进入课表页面后点击上传才解析。
- 长江大学教务插件 `v1.0.41` 已补齐正式版安装清单，插件市场可以正常显示和安装。
- 备份支持 ZIP 导入导出，覆盖课表、课程、事务、笔记、图片、提醒、插件记录和设置等数据，并在导入前显示变更摘要。
- 学期统计支持点击或长按周柱查看具体数量，柱顶直接显示每周课程数。
- 课程、事务、插件主页、教务查询和管理列表统一了深浅色、按钮、弹层、筛选和多选交互。

## 教务导入

- 已安装插件的学校优先显示插件导入。
- 插件导入遇到问题时仍可使用通用导入。
- 未收录的学校可以直接输入教务系统地址。
- 导入失败时保留旧课表，并显示没有课表、没有课程或字段不完整等具体原因。
- 长江大学插件支持双教师、实验组别、成绩、学籍、培养计划、校外成绩和考试信息，并由插件独立维护更新日志。

## 小组件

- 今日课表显示课程和事务，状态胶囊与课程结束提醒点不会重叠。
- 日历小组件支持周视图和月视图，顶部图例在窄尺寸下也不会被截断。
- 小组件主题可以独立跟随系统、应用或手动选择。

## 兼容与数据

- 覆盖安装会保留现有应用数据。
- 旧版事务和分享码保持兼容。
- 正式版使用 stable 更新源。测试版更新仍可在应用设置中单独开启。
