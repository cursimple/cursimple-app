# v0.7.4 · 测试版

本版本原先误标为正式版，现已更正为测试版；原有安装包与版本号保持不变。

这一版可以在课表上加自己的事务，每门课也有了自己的备忘录；设置页重新整理了一遍，上课提醒也更靠得住。

## 在课表上加事务

「管理列表」里点「添加事务」，填好日期和起止时间，组会、社团、约球都能直接排进课表。和课撞上的并排放在课旁边，按真实时间只占自己那一段；好几件叠在一起就合成一个「⋯」，点开逐条看。

![课表上的事务](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.4/docs/release-notes/images/v0.7.4/schedule-events.png)

## 备忘录

侧边栏新增「备忘录」，每门课一个笔记本。可以写复选框清单、设优先级和截止时间、把要紧的置顶；顶上一眼看到待办、今天到期和已逾期。

![备忘录](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.4/docs/release-notes/images/v0.7.4/memo.png)

## 双指缩放课表

在「设置 › 显示 › 交互」打开后，双指就能把课表放大到 300%，放大后可以任意方向拖着看。表头和节次栏固定在边上，点右上角「恢复原比例」回到原样。

![双指缩放课表](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.4/docs/release-notes/images/v0.7.4/pinch-zoom.png)

## 上课提醒挂上状态栏

支持实时活动的手机上，上课提醒会在状态栏时钟旁挂一个「10:00上课」的胶囊，在通知栏里也单独置顶，不和普通通知挤在一起。默认打开；系统里没放行时，打开 App 会引导一次。

![状态栏胶囊](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.4/docs/release-notes/images/v0.7.4/live-update.png)

## 设置页重新整理

顶上多了搜索框，「周末」「背景」这样搜一下就能直达。「常用」单独一块，放哪几项自己定：点「＋」挑，或者把下面任意一项长按拖上来。右上角可以在列表和网格之间切换。

![设置首页](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.4/docs/release-notes/images/v0.7.4/settings-home.png)

## 颜色都用调色盘选

课程文字、卡片、表头、网格线等所有颜色都换成和主题色一样的调色盘：拖色块、选色相，或者直接点常用色。原来的 R、G、B 数值滑杆拿掉了。

![调色盘](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.4/docs/release-notes/images/v0.7.4/color-picker.png)

## 提醒更靠得住

- 不再常驻「正在守护」通知：退出 App 后由后台定时巡检守着，被系统清掉的上课提醒和闹钟会自动重新挂上。「提醒守护」改名为「静默守护」，默认打开，以前关掉过的升级后也会重新打开。
- 提醒的时刻错过了、但还没上课，打开 App 时会补发一条，每节课最少提醒一次。
- 第一次打开 App 时会问一次通知权限，拒绝之后不再追着问。
- 「上课通知」新增「通知弹出引导」：按这台手机列出要放行的几项（通知、悬浮横幅、悬浮窗、状态栏胶囊、后台弹出界面），点一项就跳到对应的系统设置。
- 「预览当前样式」改为弹出真实的下一节课，查不到课时才用示例；被系统拦住时会说明原因并直接打开对应的设置。

## 更多手机适配

- 跳转系统设置不再「点了没反应」：一个页面打不开就换下一个，都打不开时落到应用详情页，再不行会提示手动去找。
- 补上华为、荣耀的「受保护的后台应用」入口，以及 OPPO / 一加 ColorOS 新版的自启动和权限页。
- 状态栏胶囊：ColorOS 上系统回报「不支持」其实能显示，现在按支持处理；三星 One UI 8.5 起也能显示。

## 课表与小组件

- 事务按时间插在课间、早上第一节前或晚上最后一节后时，课表会在那里插出一段，删掉后自动恢复原来的排版；日视图里事务也按时间排在各节课之间。
- 时间重叠但起始节次不同的两门课，以前会压在一起，现在左右并排。
- 小组件上点课程列表下面的空白处也能打开 App；按下课程时的阴影和卡片圆角对齐，不再多出一圈。
- 事务和备忘录会跟着备份与恢复走，换学期、重新导课都不会丢。

## 其他改进

- 设置子页里的分组不再折叠，内容直接铺开；「课表样式」的预览缩小后固定在顶上，所有样式设置在同一页。
- 检查到新版后，那一行直接出现「更新」按钮，点一下就下载，下完直接安装；点这一行看更新内容。侧边栏的「检查更新」和版本号点一下就弹出更新窗口。
- 双指缩放时画面更跟手：捏合过程中不再每一帧重新排版，松手后再按最终倍数排一次。
- 品牌卡片样式在系统允许状态栏胶囊时优先上胶囊，不允许时照旧显示卡片。状态栏胶囊只显示上课钟点，窄胶囊里也能完整露出来。
- 放假安排改为每次打开 App 联网时静默更新，并提前取好往后两年已发布的安排。

## 修复

- 「长课名自动缩小」只按字数缩，格子里明明还空着一截，地点却不显示；现在按格子实际剩下的空间缩，课名和地点尽量都放全。换了系统字体的手机上更明显。
- 上课提醒写的「还有多少分钟」是提前多久的固定值，闹钟晚到时会报错时间；现在按实际时间现算。
- 同一节课的提醒不会重复弹出，课已经开始后也不再补弹。
- 悬浮窗样式的提醒可以往上或往两边滑走，不用等它自己消失。
- 「预览当前样式」在提醒时间过了、课还没开始时会跳到再下一节，现在显示的就是真正的下一节课。
