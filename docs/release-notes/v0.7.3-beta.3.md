# v0.7.3-beta.3 更新内容

这一版带来了上课提醒和拖动调课，临时停课与课程详情也顺手打磨了一遍。

## 上课提醒

快上课时弹一条，下节什么课、在哪上一眼看清。样式跟着主题色走，悬浮窗带毛玻璃和入场动效。

![上课提醒悬浮窗](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.3-beta.1/docs/release-notes/images/v0.7.3-beta.1/class-notice.png)

## 拖动调课

两天的课并排摆开，长按拖到另一天的某一节，松手确认就调好了。

![拖动调课](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.3-beta.1/docs/release-notes/images/v0.7.3-beta.1/drag-swap.png)

## 点一下就停课

选好日期，当天的课全列出来，点「停课」就记下，不用再查节次、手填。

![临时停课](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.3-beta.1/docs/release-notes/images/v0.7.3-beta.1/cancel-course.png)

## 课程详情更全

从教务导入的课，详情里多了课程序号、课程代码和学分。

![课程详情](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.3-beta.1/docs/release-notes/images/v0.7.3-beta.1/course-details.png)

## 更多新功能说明

- 上课提醒有系统原生、品牌卡片、悬浮窗三种样式，在「提醒」页里切换；悬浮窗需要悬浮窗权限，锁屏时自动改用系统通知。
- 拖动调课：调过去的课在课表上标「调」，再拖回原位就是撤销。
- 临时停课只停点中的那一门，同一时段的其他课照上；点错了点「恢复」。
- 课程详情的附加信息需要插件支持，长江大学插件已支持，重新导一次课即可看到。

## 导课与网页登录

- 教务网页的账号密码可以像浏览器一样记住，下次打开自动填好。
- 部分学校的校园 VPN 网页在 App 里加载不出来、一直卡着，现在补上了老站需要的运行环境。
- 长江大学插件更新到 1.0.34：修好了卡在「正在抓取课表」的问题，抓取从约 19 秒缩短到 3 秒左右。

## 课表与小组件

- 课表格子放得下多少字就显示多少，地点不再被硬截成一行，「@」和地点排在同一行。
- 导出课表图片时，周末没课也照样画出来，一眼看到整周全貌。
- 小组件和通知里的节次以「第一节」这样的名字为主，「1-1」小一号跟在后面；跨节的课只写节号。
- 「下一节课」小组件默认两行高，时间不再被截掉。
- 没设上课地点的课也能直接设置分周地点。

## 其他改进

- 侧边栏「提醒」分成「闹钟」和「提醒」两页，响铃的叫闹钟，上课弹的叫提醒；「全部课程」改名「管理列表」。
- 设置子页里的分组可以折叠，点标题展开或收起；从子页返回时停在原来的位置。
- 更新公告改成翻页展示，亮点配图，会自动轮播。

## 修复

- 被手动改过的作息表会盖住插件的作息，导致小组件、闹钟里所有课都显示成同一节，时间也对不上；现在各处统一以存储的作息表为准。
- 拖动调课时，已经挪过的课再拖一次会复制出一份，原位置也还在。
- 拖动调课后小组件与闹钟没有立即刷新。
- 调课确认里单节课写成「第 3-3 节」。
- 更新公告自动翻页有时停在两页中间，也滑不动；现在翻页动画不会被打断在半路，手动滑动随时可用。
- 导课和同步课表前先检查插件有没有新版，有新版先升级再导课，升级装好后自动接着导课；导课页和插件页直接标出新版本。插件升级后旧版本文件会自动清理，市场上的版本比本机旧时也不再误报「可更新」。
- 点课表空格快速加课时，上课地点旁边也有「逐周设地点」的按钮了，和新建、编辑课程一样。快速加课顶部的节次也改用「第二节」这样的名称。
- 主题配色新增「自定义颜色」：打开调色板任选，也可以直接输入 #RRGGBB 或 R、G、B 数值。App 界面、小组件和上课提醒（品牌卡片、悬浮窗）都跟着换色。
- 小组件里的节次名和提醒时间以前固定是绿色，现在跟随主题色。
- 检查更新以前常常十几秒甚至超时：先查 GitHub API（国内经常连不上），还要等所有镜像都返回、再把十几个下载镜像挨个测速。现在先从国内 CDN 读一份版本清单，一次检查不到一秒；镜像按实测速度重新排序，去掉了失效的。
- 自动检查更新以前实际只在第一次生效，之后有新版也不弹窗。现在每次打开 App 都会检查，开着时每半小时再查一次，发现新版就弹窗提醒；点「下次再说」后，下次打开还会提醒。
- 更新公告里的说明改从国内 CDN 读取，打开更快。
- 点课表空格快速加课时，起始周和结束周不再预填，和新建课程一样由自己填写。
