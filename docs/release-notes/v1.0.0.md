# 1.0.0 · 正式版

课简 1.0.0 将课表、事务、教务导入、备忘录、小组件和数据迁移整理成一套更完整的日常学习工具。这个版本带来更清晰的课表布局、更稳定的教务导入、更完整的本地备份，以及贯穿应用的界面和交互优化。

## 从教务系统导入课表

- 在添加菜单中打开“从教务系统导入”，按学校名称、拼音或首字母搜索学校。
- 已安装插件的学校会优先显示“插件导入”。没有插件时可以使用“通用导入”，插件导入遇到问题也可以切换到通用导入。
- 学校列表支持右侧字母索引、连续滚动和网址入口。名单中没有你的学校时，可以直接输入校外可访问的教务系统网址。
- 通用导入只会在你进入真实课表页面并点击“上传课表”后解析当前页面，不会打开页面就自动抓取。
- 解析失败会保留在导入页面，并说明是没有找到课表、没有识别到课程，还是部分课程缺少课名、周次或节次。数据不完整时整次导入会取消，不保存残缺课表。
- 支持常见的网格、转置表、长表、卡片布局、位置布局，以及单双周、区间周次、中文节次和多种字段写法。
- 成功导入后优先使用教务系统提供的作息时间。没有可靠开学日期时保留“请设置开学日期”的提醒，并按最早有课周进行预览，不会擅自写入日期。

## 课表与事务

- 重叠课程按实际时间布局。时间不同的课程左右分栏，完全相同的课程合并到同一张卡片，卡片左上角显示数量。
- 同一时段出现三门或更多课程时，保留主课程并把其他课程收进展开入口。展开后会区分本周上课和非本周课程，并显示具体周次。
- 事务使用与课程一致的时间布局。两个重叠事务保持左右分栏，更多事务才进入展开入口。课程和事务同时存在时，课程优先显示，事务保留在后方。
- 日期标题会显示当天事务数量。单击有事务的日期查看当天事务，长按日期打开节假日、调休和停课设置。
- 管理列表支持课程和事务分开管理、长按多选、批量操作、事务拖动排序和来源筛选。没有插件事务时不会显示多余的来源筛选。
- 删除的课程进入回收站。回收站支持查看完整课程信息、恢复和清空，恢复与清空都需要二次确认。
- 课程详情改为居中的详情窗口，地点、老师、周次和时间集中展示。同一位置的多门课程可以用箭头或左右滑动切换。
- 编辑课程和事务时，保存操作固定在可见区域，选择日期和节次可以多选，节次优先使用当前作息表中的名称。

## 课程结束提醒

- 课程结束前两周开始提示，倒数第二周显示数字角标“2”，最后一周显示“1”。
- 课程卡片保留原本颜色，边框使用对应课程色的轻量发光效果，不再用整块变暗来区分。
- 课程详情、课表顶部图例和桌面小组件保持同一套提示逻辑。
- 这个功能位于“设置 → 显示 → 课程结束预警”，默认开启。

## 学期统计

- 统计页提供总课量、教学时长、早八、晚间课、课程最多周、课程最多日和课程排行等信息。
- 每周柱状图上直接显示数字，点击或长按可以查看该周的课程明细。
- “课程最多周”“课程最多日”“早八”和“晚间课”都可以展开查看完整课程列表。

## 分享、备忘录与本地备份

- 分享码支持更紧凑的压缩格式，同时保留旧版本分享码的读取能力。
- 分享内容可以携带作息时间、课表名称和来源显示信息，导入后可以选择是否使用分享方的作息时间。
- 备忘录支持图片、待办、清单和课程关联内容，图片会随笔记一起保存在应用数据中。
- 设置中新增独立的“备份数据”入口，位于 WebDAV 上方。进入后直接选择“导入”或“导出”。
- 导出支持全量或按类别选择，生成 ZIP 压缩包。类别包括课表、课程、事务、笔记、备忘录、小组件设置、提醒、插件记录等。
- 导入前只显示新增、修改和删除的内容，并显示笔记图片变化。没有变化的内容不会列出，备份中没有包含的类别会保留在设备上。
- 导入需要确认后才会覆盖匹配数据。失败时会尝试恢复导入前的数据，避免部分恢复造成数据缺失。

## 小组件与提醒

- 今日课表、周课表、下一节课、提醒和课程胶囊小组件统一跟随应用主题。
- 小组件默认显示事务，也可以在小组件设置中关闭。
- 课程结束提醒在小组件中以右上角数字角标和柔和边框显示，图例会解释“2”和“1”的含义。
- 今日课表标题可以打开应用内日期选择器，直接跳转到指定日期。
- 小组件的卡片之间保留清晰间距，避免多条课程粘成一整块。
- 开发者页面新增闹钟测试，便于检查应用内闹钟链路。

## 界面与交互

- 课表样式、课表显示和相关设置页面保留顶部实时课表预览，调整选项时可以立即看到变化。
- 主题、明暗模式、课表样式、课表背景和小组件背景可以从侧边栏快捷入口选择。
- 管理列表的课程与事务 Tab 使用平滑的横向切换动画，搜索、筛选和滚动状态保持稳定。
- 新手流程改为可跳过的图文介绍，权限页面先展示各项权限和当前状态，用户可以按需授权。
- 空状态、导入提示和占位文案进行了整理，并减少不必要的符号和装饰。
- 课程、事务、插件页面、备份页面和导入页面统一了按钮、弹层、图标、圆角和深浅色主题适配。

## 稳定性与数据安全

- 教务页面的 WebView 兼容性增强，减少旧教务系统首页出现空白或残缺页面的情况。
- 教务系统连接失败、登录过期、刷新超时和空结果会分别提示，刷新失败时保留上次成功数据。
- 插件主页由插件自身提供页面和业务内容，主应用只提供通用容器、登录、存储和生命周期能力。
- 插件、组件和主体更新日志分开维护，学校插件的专属更新不会混入课简主体公告。
- 导入、下载、ZIP 备份和插件包解析增加了格式、大小、路径和权限校验。
- 版本升级保留应用数据。不同签名的安装包不能直接覆盖安装，跨签名迁移请先导出本地 ZIP，再安装新包并恢复数据。
