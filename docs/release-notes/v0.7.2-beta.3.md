# v0.7.2-beta.3 更新内容

这一版集中打磨了导出、临时调课、小组件与课表显示的一批细节。

## 新增：导出课表图片默认导出全部周

右上角加号里的「导出课表图片」现在默认画整张课表——所有周的课一次全画出来，限定周次的课会在块上标出周次，同一门课按单双周拆开的多条会自动并回一块。想只发某一周的，切到「单周」再选周次即可。

顺带修掉两个老问题：

- 某些课（如「硬笔书法」）在图里被画成灰色，看着像那周没课。原因是八种底色里有一种本身偏灰，课名哈希撞上就成了灰块；现在八色全部改为有彩色。
- 全部周模式不套用假日与临时调课这些只属于某一天的安排，被假日盖住的课也会如实画出来。

## 新增：临时调课支持只调某几节

以前调课只能整天替换，现在可以「只调指定节次」——某一天的第几到第几节改上另一天的课，其余节次保持不变。课表、提醒、导出、日历同步都按节次分别归属。

临时调课的界面也重做了：

- 「补课/调课」与「临时取消」改为上方两个 Tab，切换时下方的表单与规则列表跟着切，关系一目了然。
- 日期从「未选择」起步，不再默认填今天；调课日与来源日相同、或节次范围无效时按钮禁用并给出提示，不会再一点「添加」就落下一条没选过的规则。
- 删除单条、清空全部、以及表单里填了内容没添加就想关闭，都会二次确认。

已有的调课记录完全兼容，升级后原来调好的不会丢。

## 新增：课表文字放不下时的省略号可关

课表格子放不下的文字，现在默认不再用「…」收尾，而是能显示多少显示多少，省下的位置多放一个字。想一眼看出哪里被截断的，可在「设置 → 课表文字」里打开「截断显示省略号」。

## 修复：小组件不跟随应用语言

小组件与提醒的文字之前一直停在应用启动那一刻的语言，改了应用语言也不变。现在每次刷新都按当前语言重新渲染，改完语言小组件立刻跟上。

## 修复：课表上仍显示学校名

有的教务插件把学校名当成课程徽章推下来，于是格子里每门课都挂着「长江大学」。一份课表就一所学校，校名和写在地点里一样没有信息量——现在纯学校名的徽章不再显示。

## 修复：课程详情右上角在放假日仍显示「本周」

放假那天点开课程详情，右上角只按周次判断，会显示「本周」，像是照常上课。现在放假日显示「放假」、临时停课显示「已停课」，压过周次判断。

## 其他

- 点小组件进应用、自动检查更新，两项默认改为开启（此前手动关过的不受影响）。
- 「全部课程」页适配横屏：屏幕矮时页头收成两行，给列表让出空间。
- 自己加出来的空白周，周次面板里右上角多了一个叉可直接删除（仍需二次确认），不必再靠长按。
