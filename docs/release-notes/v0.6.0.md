## 课简 v0.6.0

自 v0.5.0 起累计 70 次提交。这一版重写了插件平台，补齐了课表编辑与提醒能力，并把界面文案全部外移以支持中英切换。

### 插件平台

- 插件改为 manifest + WebView 会话架构，脚本可热更新，无需随应用发版。
- 插件来源切换到 GitHub 注册表，支持读取 stars、按日刷新市场索引并缓存到本地。
- 插件详情页可直接从 Release 安装并显示版本，安装完成后自动退出详情页。
- 区分同 ID 插件的安装来源，本地与远程安装互不覆盖。
- 插件可自定义 User-Agent、控制 WebView 界面，支持网络抓包与稳定的网页登录态。
- 新增结构化日志体系与应用内日志查看器。

### 课表

- 新增节次上课时间编辑，支持套用作息模板后逐条调整。
- 支持手动录课，长按可拖动调整课程位置。
- 新增课程备注，桌面小组件同步显示。
- 新增课程冲突检测、课表图片分享与外观预览。
- 自定义配色可跟随亮暗主题调整。
- 支持节假日调休，可导出 ICS 日历文件。

### 提醒与小组件

- 支持自定义闹钟铃声与提醒方式，占位课可从下拉选择节次标签。
- 闹钟增加静默巡检与自动补建，系统闹钟被清理后可恢复。
- 上课时段可自动切换手机状态，下课恢复。
- 小组件统一开学日期来源，修复空态、尺寸适配、点击跳转与背景图。

### 同步与导入

- 新增 WebDAV 同步与私有目录访问，可从云端导入课表。
- AI 识图导入支持配置超时时间。

### 界面语言

- 新增中文 / English 切换，跟随系统或手动指定。
- 界面文案全部移入资源文件，逻辑层不再产出面向用户的文字。
- 节次名称跟随当前语言显示；已存的标签保持原文，按标签匹配的提醒规则不受影响。

### 修复

- 未设置开学日期时不再显示「第 1 周」，也不再强行显示课程。
- 课表网格补位行改为沿用同一单位与真实节号，不再出现「第一大节」与「第6节」混排。
- 更新检查遇到代理返回的非 JSON 响应时不再当作成功，改为回落到其他源。
- 数据缺失或损坏时如实报错，不再编造可用状态。
- 修复备份恢复、学期删除与导入落盘。
- 修复提醒误触发、静默失败与设置丢失。
- 抓包失败不再冒充一次成功的响应。
- 收紧凭据外发、资源上限与时区处理。

### 构建

- 启用核心库脱糖，最低支持 Android 7.0（minSdk 24）。
- 发布产物包含 armeabi-v7a、arm64-v8a、x86、x86_64 与 universal 五个 APK。
