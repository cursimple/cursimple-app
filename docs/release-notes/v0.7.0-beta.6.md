## 课简 v0.7.0-beta.6

预发布版本。这一版补上首次进入的分步引导，把提醒与后台统一到应用时区，
并修掉背景裁切、节次列、课程卡片与更新公告上的几处显示问题。

### 新增

- **首次进入的分步引导**。免责声明与开学日期提醒过后依次圈出侧边栏、加号与周次区域，
  逐条说明从哪里导入课表、怎么手动加课、怎么切换周次；圈框位置由控件自己上报，
  不同机型、字号与系统栏高度下都落在控件上。
- **小组件的上课状态**。每行按当前时刻标出「上课中」与「即将开始」，正在上的那一节
  换更深的底色并配深绿徽章；这两个状态比提醒标记优先占用徽章位，
  刷新点位也补上了转入「即将开始」的那一刻。
- **更新说明按 Markdown 渲染**。标题、列表、粗体、行内代码与链接按样式显示，
  续行按中英文规则合并，不再是一大段原始符号。

### 修改

- **提醒与后台改用应用时区**。设置里的时区此前只作用于界面，提醒排程、自动静音、
  闹钟编辑、小组件边界刷新与日历导出仍按设备时区算，跨时区时会响错时刻。
- **开学日期不再被插件静默改写**。没有定过开学日期时才从插件同步的作息里继承，
  定过或主动清空之后不再被写回，设置里也标出日期来自插件同步。
- **设为当前周先确认**。这一步会按今天反推并覆盖开学日期，周次、提醒与小组件都跟着重算，
  弹窗里写明开学日期会变成哪天。
- **点击小组件直接进应用**。不再经广播中转再启动界面，桌面上就是被点的那块展开进应用，
  没有中间那层遮罩。
- **权限被永久拒绝时改跳系统设置**，不再反复弹一个不会出现的系统对话框。

### 修复

- 背景裁切拖不到图片左右两端，预览与实际落盘取的不是同一块；预览图另按长边降采样。
- 表头字号调大后「第一大节」被折成每行一个字，把下面的起止时间挤出行高而被裁掉。
- 课程卡片里课程名与教室地点互相挤压，地点会越出卡片边界；超出部分现在直接截断。
- 更新完成后的版本公告一直停在获取中，取不到内容时没有重试与发布页入口。
- 平铺背景下卡片高度设置不生效，此前没有任何说明。
