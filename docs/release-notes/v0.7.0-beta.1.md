## 课简 v0.7.0-beta.1

预发布版本，自 v0.6.0 起累计 14 次改动提交。这一版把节假日改成同步公开数据集，
放假不再抹掉课程，另外新增了多套作息、写入系统日历和全部课程页。

预发布不会推送给应用内更新检查，需要手动下载安装。

### 节假日

- 节假日改为同步公开数据集，不再逐年硬编码；离线时回落到内置数据，同步过的年份内置不再参与。
- 内置数据按放假通知补全完整放假区间，此前只收录法定假日本身，国庆写成 1-5 号而不是 1-7 号。
- 假日与未开学不再抹掉课程，改为灰显，课表、日视图与小组件三处一致。

### 提醒

- 放假默认照常提醒，跳过假日改为可选开关。
- 假期前一天晚上给出提示，通知里可直接关掉次日的提醒。
- 修复拖动手动课程改动节次后，单课与考试提醒规则没有重建，该课提醒静默失效。

### 课表

- 一周可从周日起，教学周编号仍按周一锚点计算。
- 长按课程块上下边缘可拖动调整占用节次，设置里开关默认关闭，拖动后弹窗二次确认。
- 新增全部课程页，可搜索、按星期 / 名称 / 来源排序，并直接编辑手动课程。
- 课程详情底部按钮居中，长文案不再把布局挤成竖排，铃声选项改为带边框按钮。

### 作息与日历

- 支持多套作息时间表，可新建、复制、重命名与删除；学期可绑定作息，切换学期自动选中对应那套。
- 课表可写入系统日历账户：按周重复的课合成一条重复事件，停课的周写入排除日期，调课的那几次单独成条。
- 写入的事件 id 记在本机，支持一键撤销；重复写入前先删掉上一次的内容，不会堆出多份课表。
