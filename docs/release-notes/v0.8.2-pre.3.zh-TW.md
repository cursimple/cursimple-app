# 0.8.2-pre.3 · 預發布測試版

0.8.2-pre.3 為 pre 分支測試版本，新增共同空閒時間、學期管理與學期統計，並補充課程待辦、出席紀錄和匯入失敗診斷。本版本僅供測試體驗，不推送至正式更新來源。

## 共同空閒時間
- 新增選單中的「共同空閒時間」：貼上同學的分享碼，即可比對兩人課表，列出每週兩人都沒課的時段，方便約飯、約小組討論。資料只在本機計算，不需要伺服器。

## 學期管理與統計
- 學期管理頁可將既有學期「複製」為新學期，保留課程與時間設定；週次和提醒預設不帶過去，提醒可選擇保留。
- 舊學期可「封存」，封存後仍可回看與統計，不影響目前學期。
- 新增學期「統計」頁：總課時、每週課量、各門課占比與出席匯總。

## 課程細節
- 課程可新增待辦，課表卡片上顯示未完成數量。
- 課程可記錄出席（出席、缺席、請假），統計頁自動匯總。
- 課程表單分區重排，週次選擇獨立成段；課程外觀支援預設與漸層色。

## 匯入、備份與設定
- 匯入失敗時彈出診斷對話框，提供原因、建議和可複製的詳情。
- WebDAV 支援每週自動備份，自動備份數量超出後清理最舊的一批。
- 設定頁按顯示與樣式重新分組，分組可摺疊；新增時間欄寬度設定。
- 備忘錄支援插入圖片、複製文字。
