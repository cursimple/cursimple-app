# v0.7.1-beta.5 更新内容

## 课名字号恢复统一

上一版按课名长短自动缩字号，结果一屏里有的大有的小，参差不齐反而更难看。现在默认所有课名字号一致。

想要「宁可小一点也要看全」的，去 设置 → 课表外观 → 文字样式 打开「长课名自动缩小」。

## 格子里不再显示学校名

同一份课表本来就都在同一所学校，把「长江大学」印在每个格子里既占地方又必然把教室号挤掉。

之前的剥离只认结尾的学校名，还要求过半数地点写法一致才动手——教务系统里「东13-306长江大学」和「长江大学东校区东13-306」两种语序混着来，这条线凑不够，于是整份课表都没剥成。现在两种语序都认，同一所学校带不带校区也都算一起。

## 格子里的地点只占一行

地点折三四行会把课名挤没。现在一行放不下就省略号收尾，完整地点点开课程详情看。
