# v0.7.2-beta.2 更新内容

修复 beta.1 未能解决的两个问题。

## 修复：新增周次后顶部周数不更新

beta.1 修的是总周数的计算，但没有触及真正的原因，所以现象没有变化。

真正的原因是翻页监听：它只在起点变化时重建，内部却读取着创建那一刻的页数。新增一周后页数变了，监听里仍是旧值，于是翻到新增的那一周会被误判成「添加周」页面而直接忽略，周偏移不再更新，顶部周数就停住了。

现在监听始终读取最新的页数与起点。

同时把「加一周」从「界面读当前值 → 加一 → 写回」改为在数据层一次性完成读改写：界面上的数值可能尚未回流，按旧值写入会吞掉前一次的新增。

## 修复：课程卡片仍显示学校名

剥离学校名时有一条兜底逻辑——剥完为空则原样返回。因此地点只填了「长江大学」的课程，卡片上会一直显示「@长江大学」。

现在区分两种情况：地点中除学校名外还有教学楼或教室号的，剥离学校名后显示其余部分；只有学校名（含「长江大学东校区」这类写法）的，整行不再显示——一份课表对应一所学校，写出校名没有信息量，不如把空间留给课程名。
