## 课简 v0.7.0-beta.4

预发布版本。这一版重排了设置界面与闹钟界面，课表默认把全部节次平铺进一屏，并补上更新公告与版本回退。

### 新增

- **更新公告**。装完新版本首次进入时，展示该版本在 GitHub Release 上的发布说明。
- **回退到正式版**。关闭测试版更新后再检查，若线上正式版版本号低于当前测试版，
  会提示可以回退并附上正式版的发布说明；回退需要先卸载，弹窗里已注明请先备份课表。
- **纵向排布设置**（设置 → 外观 → 显示 → 显示范围）。默认「平铺全部」把所有节次
  压进一屏，课名自动省略；选「固定行高滚动」则保留设定的行高，右侧显示滚动滑块，
  一眼能看出下面还有课。
- **侧边栏换主题与换背景**两个直达入口，不必再进三层设置菜单。
- **背景图裁切**。导入自己的图片时先进裁切对话框，可拖动缩放预览，按课表比例裁切后再应用。

### 修改

- **设置界面按功能重排**。根页从 13 个平铺条目改成外观、课程与时间、提醒与权限、
  数据与扩展、通用、应用更新六个分组；去掉「应用设置」「课表设置」两个纯中转页，
  课表样式与课表显示直接列在根页；课表显示、课表样式、卡片样式、小组件页内也按子分组归类。
- **闹钟界面重做**。时间改为内联的时分键盘录入，不再用表盘；铃声与提醒方式改成单行选择器；
  响铃时长、间隔、次数改成单行步进，不再把数值折到第二行。
- **日视图左右滑动**改用分页器承载，拖动跟手，滑动时能看到前后一天。
- **课表列宽加宽**。节次列收窄，课程卡片的竖条与内边距收紧，课程名能多显示一些。
- **小组件默认尺寸**。课表 4×2、下一节课 4×1、提醒 4×2，装上就铺满桌面一行。
- **关于页重排**，补上应用图标、发布通道、核心能力、项目链接与运行环境信息。
- **插件市场加载提速**。镜像文本下载从「先探测再下载」改为并发竞速，首个成功的即采用，
  并记住上次成功的镜像下次优先尝试，往返次数减半。
- 删掉两个冗余开关：「完全居中」等价于同时开水平与垂直居中，「地点前加 @」几乎无人调整；
  「显示周六」「显示周日」两个相互牵连的开关合并为「显示天数」三选一。

### 修复

- 没有配置作息时间时，课表按「起止节组合」排行会让跨节课程互相重叠，节次序号也会
  从 1~6 直接跳到 10。改为按单个节号排行，跨节课程用行跨度表示。
- 课表背景图只盖住中间的课程区，节次列与日期行仍是白底。
- 更新面板的状态文案在首次显示时被固定，切换应用内语言后不跟着变。
- 插件市场装完插件后仍显示「安装」，不会变成「已安装」或「更新」。
- 插件页按系统返回键直接回到桌面，而不是回到上一页。
