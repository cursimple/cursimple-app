# 0.8.2-pre.1 · Pre-release Test Build

0.8.2-pre.1 is a feature test build for the `pre` branch, introducing horizontal swipe to switch week, timetable palette styles and per-course custom accent colors, smart system calendar incremental sync and wipe, consolidated third-party import card, and numerous UI refinements. This build is intended for testing purposes only and is not published to update feeds.

## Horizontal Swipe to Switch Week
- The timetable grid now supports horizontal swiping gestures to seamlessly switch between weeks.
- Smooth transition animations with subtle horizontal offset and fade in/out, along with boundary damping at the first and last weeks.

## Timetable Palette Styles & Per-Course Color Selection
- 5 preset timetable color palette styles: Fresh, Morandi, Macaron, Vibrant, and Vintage.
- Course details dialog now allows selecting a unique color for individual courses or resetting to default.

## Smart System Calendar Sync
- Exported calendar events now include unique identifiers (UIDs).
- Smart incremental diff updates on subsequent syncs (cleans up removed/rescheduled classes, updates modified details, and adds new courses).
- Wipe calendar events button to cleanly purge all previously exported schedule events.

## Consolidated Third-Party Imports & UI Standardization
- Dedicated "Third-party Import" card in the Import & Export section grouping WakeUp, XiaoAI, and ICS imports.
- Standardized dialog and text input border styling for visual consistency.
- Tablet and foldable dual-pane layout adaptations, live timetable timeline, and widget improvements.
