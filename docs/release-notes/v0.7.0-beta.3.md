## 课简 v0.7.0-beta.3

预发布版本。这一版新增时区设置与测试版更新开关，并让关于页能区分不同的预发布版本。

### 新增

- **时区设置**（设置 → 应用 → 时区）。默认跟随设备，也可指定为学校所在时区，
  出国或跨时区时课表与提醒仍按上课时间计算。选择列表按当前语言显示城市名与时区名，
  按与 UTC 的偏移排序，可按城市名、时区名、标识或偏移搜索。
- **测试版更新开关**（设置 → 应用更新，最下方）。默认关闭，开启前二次确认。
  开启后更新检查会包含预发布版本，此前预发布不会出现在应用内的更新检查里。

### 修改

- 版本号带上预发布后缀，关于页据此可区分不同的预发布版本。
- 发布流程校验标签与版本号一致，不一致直接中断构建。
