# v0.7.1-beta.9 更新内容

紧接 beta.8 的一批修复，主要来自 vivo 机型上的实机反馈。

## 精确闹钟未开启时会一直提示

缺少精确闹钟权限时，提醒会被系统丢进一个模糊的时间窗，迟到十几分钟很常见，但界面上看不出任何异常。

闹钟页顶部新增一条常驻提示，直接给出开启入口。它不是弹一次就消失的提示：每次回到前台重新检查，没开就一直显示，开了自动消失。

## 一键添加小组件：不再让你对着没反应的按钮反复点

`requestPinAppWidget` 返回成功只代表请求被系统受理，桌面完全可以转头丢掉。vivo 的桌面（com.bbk.launcher2）实测就是如此，把「桌面快捷方式」权限开着也一样，且系统没有任何接口能提前问出来。

- vivo / OPPO 机型上点击添加**直接给出手动添加步骤**，不再发送那个注定被忽略的请求、不用再等十几秒。
- 其它机型仍然正常尝试一键添加；若实测失败，会记住这台设备，之后同样直接走手动步骤。
- 手动步骤里保留「再试一次一键添加」，换了桌面或系统升级后可以随时退回自动流程。
- 自检信息中的「一键添加」一项会如实区分「系统声明支持」与「这家桌面不响应」。

## 厂商权限入口与时机

- **自启动 / 后台弹出界面**点进去会直接停在课简这一页，不用再自己在几百个应用里翻。vivo、小米、OPPO 均已适配；华为与荣耀没有稳定的单应用权限页，仍会落到应用详情页。
- 这两项权限系统不提供任何查询接口，应用读不到真实状态。与其一直显示「需手动确认」，现在改为可由你自己勾选「已开启」，勾过之后不再提示。
- 添加小组件前若这项权限尚未确认，会先提示一次；选择「先不管」则下次仍会提示，直到确认开启为止。

## 背景设置改为独立页面

原先课表背景与小组件背景挤在同一页的两个标签里，而且只有侧边栏的「换背景」能进到完整设置。

现在改成独立的二级菜单，「背景」下分「课表背景」与「小组件背景」两页，各自有预览、选图裁剪、透明度滑块与清除。侧边栏与设置 → 外观都能进入，内容完全一致；从侧边栏进入时返回直接回到课表，不会先掉进设置里。

## 表头信息不再看不全

- 表头的星期、日号与下方小标签（节日名、调休、按某天）全部改为按列宽自动缩放字号。此前星期与日号是直接裁切，大字号下「10月」会被切掉半个字；小标签则会被省略成「按1…」，看不出按的是哪一天。
- 修复调休日未预留标签行高度的问题。
- **双击日期**现在会完整列出这一天的全部状态：今天、节日名、调休补班、按哪一天的课上（含星期）。表头受列宽所限显示不全时，双击即可看到完整内容。

## 其它界面修复

小组件面板内的提示改用浮层显示。此前它被绘制在面板下方，需要先关闭面板才能看到。

## 华为系统服务

新增 `sync_data_to_system_service` 声明，允许华为 / 荣耀的系统服务（智慧助手、系统日历）读取课表数据。这是华为侧系统卡片的前置开关，本身不会主动上传任何数据。

## 文案

自检信息等处的措辞调整为面向用户的表述。

## 周次

- **自己添加空白周**：周课表翻到最后一页是一个加号，点一下往后接一周空白课表；周次面板的网格末尾也有同样的加号。实习周、考试周这类没有课但确实存在的周，课程里推不出来，现在可以自己补上。
- 自己加出来的空白周**长按可删除**（课程推导出来的周不能删，删掉下次仍会算回来）。
- **双击顶部周次**直接回到本周。
- 修复：在「添加周」页点加号后会原地落到新增的那一周，但顶部周次没有跟着更新。

## 课程周次支持自选

课程编辑里的周次新增「自选」一档，点开是整学期的周次矩阵，逐周点选。确认后起止周输入框收起，只留「已选 5 周 / 3、5、7、11、13」一行摘要，右侧常驻「修改」。切回全部周 / 单周 / 双周即恢复区间输入。

同时修复：判断已有周次属于哪一档，过去是「全是奇数就算单周」，3、5、11 这类不规则周次会被归入「全部周」，**打开编辑器即被区间改写成 3 到 11 的每一周**，保存后凭空多出数周。

## 课表显示

- **横屏可用**。平铺模式此前既不滚动也不缩放，节次放不下时底部几节完全够不着；横屏高度只有竖屏一半，必然放不下。现在放不下会自动转为可滚动，往下拖即可看全（竖屏节次较多时同样适用）。
- **课程名只显示放得下的整行**。此前超出部分直接裁切，最后一行会被从字中间切开，露出小半个字。
- **同一格有多门课时，长按可选择编辑哪一门**。此前固定编辑最上层那一门。
- 课程详情里的「同位置 N 门」改为翻页式：左右箭头切换、整条替换课名，配圆点指示当前是第几门。长课名不再被挤成两行或省略。

## 导入与调休

- **教务系统同步前先看变化**：有增减时列出新增/减少了哪几门（超过 5 门折叠），再由你选择覆盖当前课表或另存为新课表。扫码导入同样支持，且默认另存新课表。
- 差异按「课名 + 星期 + 节次 + 周次 + 地点」比对，不按课程 id（教务系统每次抓取 id 都会变）。
- **调休补班日在表头标出**，空白格双击也能打开当天的放假 / 调休设置。
