# 0.8.2-pre.3 · Pre-release Test Build

0.8.2-pre.3 is a test build for the `pre` branch. It adds shared free time, term management and term statistics, and brings course todos, attendance records and import failure diagnosis. This build is intended for testing purposes only and is not published to update feeds.

## Shared Free Time
- New "Shared free time" entry in the add menu: paste a classmate's share code to compare your timetables and see the weekly slots where both of you are free, handy for meals or group discussions. Everything is computed locally; no server is needed.

## Term Management and Statistics
- The term management page can copy an existing term into a new one, keeping courses and timing settings. Weeks and reminders are not carried over by default; reminders can be kept if you choose.
- Past terms can be archived. Archived terms can still be viewed and counted, and the current term is unaffected.
- New term statistics page: total sessions, sessions per week, each course's share, and an attendance summary.

## Course Details
- Courses can have todos, and the unfinished count appears on the timetable card.
- Courses can record attendance (present, absent, leave), summarized on the statistics page.
- The course form is regrouped into sections, with week selection in its own section; course appearance supports presets and gradient colors.

## Import, Backup and Settings
- When an import fails, a diagnosis dialog explains the reason and next steps, with copyable details.
- WebDAV supports a weekly automatic backup; when there are too many automatic backups, the oldest are cleaned up.
- The settings page is regrouped into Display and Style, with collapsible groups; a time column width setting is added.
- Memos support inserting images and copying text.
