# 0.8.2-pre.1 · 預發布測試版

0.8.2-pre.1 為 pre 分支特性測試版本，帶來了週視圖橫滑手勢切週、課表個性化風格配色與單課調色、智慧系統日曆增量同步與一鍵清理、第三方匯入整合卡片等多項全新體驗與最佳化。本版本僅供測試體驗，不推送至正式更新源。

## 週課表橫滑手勢切週
- 課表格線區域現已支援左右橫滑手勢切週，翻看前後週課表更自然順手。
- 伴隨平滑橫向位移與淡入淡出動畫，到達首週與末週時具備智慧邊界阻尼。

## 課表個性化配色盤與單課專屬調色
- 新增 5 種預設風格色盤：預設清新（Fresh）、莫蘭迪灰調（Morandi）、馬卡龍甜心（Macaron）、多巴胺活力（Vibrant）、復古原木（Vintage）。
- 課程詳情中支援為任意單門課程自訂專屬色塊，並支援一鍵恢復為預設。

## 智慧系統日曆同步
- 匯出系統日曆時為行程附加專屬唯一識別碼（UID）。
- 再次同步時支援智慧增量 Diff（自動清理已刪除/調走課程、更新時間地點變更、寫入新課程）。
- 新增徹底一鍵清除已寫入日曆行程的功能，避免殘留多餘行程。

## 第三方匯入整合與介面規範統一
- 在匯入匯出頁面中新增「第三方匯入」專屬卡片，收納 WakeUp 匯入、小愛課表匯入與通用 ICS 匯入。
- 統一規範對話框與輸入框設計風格，邊框視覺層次與互動更加清晰。
- 適配平板與折疊螢幕雙欄版面配置、即時時間線與小工具互動增強。
