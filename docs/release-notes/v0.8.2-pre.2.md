# 0.8.2-pre.2 · 预发布测试版

0.8.2-pre.2 为 pre 分支测试版本，重点优化拥挤日课表布局、横屏与平板体验、小组件和导入安全。本版本仅供测试体验，不推送至正式更新源。

## 拥挤日课表布局
- 每天最多 2 列：两门课时间交叉时左右并排，不交叉的课上下排布在同一列。
- 同一时段 3 门以上时，保留离「现在」最近的两门，其余收进右下角的「⋯」，点开可查看全部，并显示时间段、教室、老师以及「正在上课 / N 分钟后开始 / 已结束」。
- 屏幕放不下时，课最少的日子自动退回单列，避免课程卡片被压成一字一行的长条；平板与横屏宽度足够时每天最多 3 列。
- 有折叠内容的日期表头显示小圆点，今天的列加淡色底；教室号在窄卡片里优先在连字符处换行。
- 左侧节次列进一步收窄，给课表更多空间。

## 横屏、小组件与导入
- 修复横屏崩溃与无法滚动，更新日志图文排版更松。
- 备忘录小组件可显示更多条目并支持滚动；新增小组件透明度、模糊与深色适配、课程胶囊小组件。
- 新增 ICS、WakeUp、小爱课表导入，课表时间线指示、晚间简报、换教室与考试提醒（默认关闭）。

## 安全加固
- 加固导入、下载、文件提供器、备份规则与插件包解析，限制体积与权限。
- 更新构建工具链依赖，替换内置旧 jQuery，加入依赖安全扫描工作流。
