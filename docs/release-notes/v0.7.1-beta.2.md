# v0.7.1-beta.2 更新内容

## 更新不用再自己去设置里翻了

- 后台自动检查更新：带 ETag 的条件请求，没新版时服务端只回 304、不带响应体，一次几百字节，15 分钟一拍
- 只有探到发布页真的变了，才去跑流量大几十倍的完整检查
- 源站连不上时退回 6 小时一次的镜像检查兜底，不会空转
- 侧边栏新增「检查更新」快捷入口，有新版时带红点

## 下载安装包有进度了

- 更新弹窗显示进度条和「已下载 12.3 MB / 28.6 MB · 43%」，不用再对着「下载中…」干等
- 服务端没给文件大小时退回不确定进度条，至少看得出还在动

## 课表格子以课名为主

- 课名按自身需要的行数占位，地点拿剩下的高度：「数据结构」不会再被挤成「数据」
- 地点能摆下就整段摆下，摆不下按剩余高度截断

## 全部课程补齐常见操作

- 每门课都有编辑、移动、提醒、删除；改过的插件课多一个「还原」
- **插件同步的课也能删了**：课表、提醒、导出、小组件里一并消失，下次同步不会又冒出来
- 删掉的课在列表上方「已删除 N 门」里可以随时恢复
- 移动带二次确认

## 从教务系统导课

- 修好登录教务系统的网页浮层尺寸：之前被父容器挤小了，取消 / 后退 / 刷新 / 上传课表那排按钮被截掉
- 登录浮层开着时按返回键退回搜索页，不再一路退到课表把整个导课流程丢掉
- 插件注册表支持声明学校别名，长江大学的插件现在搜「长江大学」「长大」「cjdx」都能找到

## 侧边栏

- 换主题、换背景下面新增「调课」和「检查更新」两个快捷入口
