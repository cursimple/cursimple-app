# 0.8.2-pre.2 · Pre-release Test Build

0.8.2-pre.2 is a test build for the `pre` branch, focused on the crowded-day timetable layout, landscape and tablet behavior, widgets and import security. This build is intended for testing purposes only and is not published to update feeds.

## Crowded-day Timetable Layout
- At most 2 lanes per day: overlapping courses sit side by side, non-overlapping ones stack in the same lane.
- When 3 or more courses share a time range, the two nearest to now stay visible and the rest fold into a "⋯" chip at the bottom right. Opening it lists everything with time, room, teacher and "In class now / Starts in N min / Finished".
- When the week cannot afford it, the least busy days fall back to one lane so cards never turn into one-character strips; tablets and landscape allow up to 3 lanes per day.
- Day headers show a small dot when something is folded, today's column gets a faint tint, and room numbers wrap at hyphens in narrow cards.
- The period column on the left is narrower to give the timetable more room.

## Landscape, Widgets and Import
- Fixed the landscape crash and missing scroll; changelog text and images are less crowded.
- The memo widget shows more items and scrolls; widgets gain transparency, blur and dark mode, plus a course capsule widget.
- Added ICS, WakeUp and AI Schedule import, a timetable time indicator, evening briefing, and room-change and exam reminders (off by default).

## Security Hardening
- Hardened import, download, file provider, backup rules and plugin package parsing with size and permission limits.
- Updated build-toolchain dependencies, replaced the bundled old jQuery and added a dependency security scan workflow.
