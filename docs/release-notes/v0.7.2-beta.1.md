# v0.7.2-beta.1 更新内容

修复 beta.9 的几处问题，并补上更新历史与若干交互调整。

## 修复：自己加的周会让周数一路上涨

beta.9 加入「自己添加空白周」后出现的回归。总周数原本会把**正在查看的那一周**也算进去，叠上新增的周之后形成自增循环：翻到最后一周 → 总周数 +1 → 又多出一页 → 再翻又 +1，周数没有尽头。

现在总周数只由课表本身与你显式添加的周决定，与当前翻到第几周无关。17 周加一周就是 18 周，翻到第 18 周它仍是 18 周。

## 课程卡片按优先级排布文字

此前课程名被省略成「汇编语言与微型…」，下方却还显示着「@东…」——最要紧的没看全，又多出一行看不懂的残句。

现在严格按 **课程名 > 地点 > 附注** 的顺序填充：

- 课程名优先占用高度，只显示完整的行。
- 课程名未显示完时，不再显示地点与附注。
- 地点要么整段显示，要么不显示，不再出现「@东…」这类半截内容。

## 课程详情的周次标记

此前无论翻到第几周，打开课程详情右上角都显示「本周」——它实际表示的是「在你正在查看的这一周有课」。

现在只有正在查看的恰好是当前教学周时才显示「本周」，否则写明周次：「第 12 周有课」/「第 12 周不上」。

## 更新相关

- **侧边栏的「检查更新」改为独立弹窗**，不再跳转到设置页。
- **设置 → 检查更新下方新增「更新历史」**：列出已发布的版本，点开查看该版本的更新内容。列出哪些版本跟随「接收测试版更新」开关——关闭时只显示正式版。

## 小组件

- 点击小组件中的课程时，触摸高亮被限制在该课程卡片的圆角范围内，不再溢出到框外。
- 小组件背景设置的三个入口（侧边栏、设置 → 外观 → 背景、设置 → 小组件）现在指向同一页面，均包含预览、选图裁剪、透明度与清除。此前「设置 → 小组件」只能选图。
- vivo 等已确认不响应一键添加的机型，手动添加提示中移除了「打开应用设置」——该权限页无法解决此问题。

## 其它

- 透明度滑块改为实时预览，拖动过程中效果即时更新。
- 插件页不再常驻显示「已刷新今日闹钟」「已加载 N 个插件」这类一次性提示。
