# 0.7.11 · 測試版

本次在 0.7.10 基礎上新增課程分週獨立設定與僅改本週、按時間錄入課程、事務按週選擇、側邊欄自訂與底欄佈局，並重新整理了小組件與管理清單。應用程式內開啟「測試版更新」後可接收本次更新。

## 課程分週獨立設定與「僅套用到本週」

點開課程詳情，支援按週獨立設定課程名稱、上課地點與任課教師，滿足單雙週輪換、臨時調課或實驗課等差異化需求：

- **詳情頁直覺標註**：當某週擁有專屬設定時，課程詳情卡片對應欄位右側會顯示 `[本週特有]` 徽標，並以柔和色標註全週期預設值（例如：`(預設：高等數學)`），當前狀態一目了然。
- **編輯時直接改，支援「僅套用到本週」**：修改欄位後，下方動態提供「僅套用到本週」（非第 1 週顯示「僅套用到第 X 週」）按鈕並附有說明提示；點擊後立即僅在當前週生效，不影響其他週次。直接點擊「儲存」則作為全週期的基準預設值。
- **分週批次設定更高效**：分週設定彈窗中提供「全部套用」、「單週」、「雙週」、「全部沿用預設」快捷按鈕，輸入框預填當前值，下方展示已自訂週次的輕量 Chip，點擊任意 Chip 即可快速回填修改。

## 課程可以直接填時間

新增、快速新增與編輯課程時，可以在「按節次」和「按時間」之間切換。選「按時間」後用時間選擇器填入開始與結束時間，課表按這個時間擺放課程卡片；單課提醒、首堂提醒、課前靜音、課程詳情、匯出日曆和桌面小組件也都改用這個時間。

不在標準節次上的課不會再被壓回整節。例如 12:10–13:30 的午間課，會插在 3–4 節和 5–6 節之間單獨佔一條，左側標出真實時間。

![按時間錄入課程](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.11/docs/release-notes/images/v0.7.11/course-clock.zh-TW.png)

![課表按真實時間錯位擺放](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.11/docs/release-notes/images/v0.7.11/grid.zh-TW.png)

按時間擺放的課程不能拖動調整，要改時間請打開編輯表單。

## 事務按週挑著重複

事務的重複方式由「每週」一個開關改成「不重複 / 每週 / 選擇週」。選「選擇週」後可以在週次格子裡點選任意幾週，事務固定落在當天對應的星期幾；詳情和清單會顯示「共 2 週：10/14、10/28」。

## 側邊欄自己排

設定裡新增「側邊欄」：項目可以拖動排序，也可以逐個關掉。關掉的項目不會消失，會收進側邊欄底部的「更多」，照常能進。課表和設定固定顯示，底部四個快捷按鈕也能整組關掉。側邊欄裡的組件最多顯示 3 個，更多的進「檢視全部」。

![側邊欄排序與隱藏](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.11/docs/release-notes/images/v0.7.11/sidebar.zh-TW.png)

## 常用頁面放底欄

安裝「佈局」組件後，可以把導覽從側邊欄換成底欄，預設是「課表 · 筆記 · 組件 · 我的」。課表固定在第一個，「我的」固定在最後，中間最多放 3 個。沒放進底欄的頁面和四個快捷按鈕都收在「我的」裡，更新紅點也合併到這上面。隨時可以在組件設定裡或「設定 → 側邊欄」裡換回側邊欄；組件停用或刪除時會自動回到側邊欄。

![底欄與「我的」頁](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.11/docs/release-notes/images/v0.7.11/bottom-bar.zh-TW.png)

![沒放進底欄的頁面都在「我的」裡](https://raw.githubusercontent.com/cursimple/cursimple-app/v0.7.11/docs/release-notes/images/v0.7.11/me-page.zh-TW.png)

## 今日安排收錄事務

「每日課程」小組件改名為「今日安排」，事務和課程按時間排在同一欄，事務帶「事務」標籤，進行中也會標出來。課簡日曆小組件會標出有事務的日子。設定 → 桌面小組件新增「在小組件上顯示事務」，預設開啟。

## 管理清單重新整理

管理清單頂部可以切換「課程 / 事務」，右下角的按鈕跟著目前頁面變化。卡片改成一屏能看更多，編輯、還原與刪除收進「⋮」選單，插件課程也能修改的提示只顯示一次。已刪除的課程可以「徹底刪除」，刪掉後不再還原，下次同步也不會被加回課表。

## 更多改進

- 今日概覽的上下課倒數精確到秒，數字等寬不會抖動；其他內容改為整分鐘重新整理。
- 桌面待辦先進入唯讀詳情，點鉛筆才編輯；浮窗高度固定，切換面板時不再跳動。
- 筆記一次可以插入多張圖片，按選擇順序排列，一次復原即可全部撤回；工具列圖示長按顯示名稱。
- 地點前是否加「@」可以在設定裡切換，預設加；地點略長時自動縮小字級，不再截掉最後一個字。
- 設定子頁的標題與返回移到應用程式頂欄，學期管理、匯入匯出等頁面開合帶過場。
- 「今日安排」和課程日曆小組件都能進入對應日期的課表。

## 修正與穩定性

- 關閉桌面浮窗（待辦編輯、課程詳情）時不再閃一下、滑一下或縮放。
- 應用程式啟動不再重繪所有桌面小組件，減少卡片閃爍；只有時區、筆記等真的變化時才重新整理。
- 小組件會在事務開始前、開始時和結束時自動更新狀態。
- 新增和編輯時，教師、地點輸入框不再一打字就彈出下拉；點輸入框只移動游標，點箭頭才列出已儲存的值。
- 切換語言後，筆記分享與匯入的文案會跟著變。

## 組件能力

- 組件介面升到 12：組件可以宣告自己提供的佈局，由課簡原生繪製；組件頁也能查詢和切換目前佈局，不合規的請求會給出提示且不改動現狀。11 及以下的組件照常可用。
- 協議細節整理進倉庫裡的 `docs/plugin-system.md`，補齊了 10、11 兩版能力說明。
