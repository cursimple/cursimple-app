# v0.7.1-beta.8 更新内容

## 退出应用后闹钟还能响

部分国产系统把「从最近任务划掉」当成强制停止，应用挂在系统里的闹钟会被一并清掉，之后没有任何事件能把它补回来，于是退出应用提醒就再也不响了。

设置 → 权限里新增「闹钟守护常驻通知」开关。打开后有一条静音的常驻通知守着进程，划掉任务时会补排一次闹钟，进程真被收走也会自己回来。重启手机（含小米那种「快速开机」）后同样会重新到位。

## 小组件翻页不再串成上一天的样子

放假那天的课是灰的，往前翻却把灰色也带了过去——桌面的列表还停在上一份缓存里。现在内容一变就让启动器重建列表，灰字与正常字每次都重新写一遍，不会留着上一天的残影。

手动翻到的那一天也记住了是哪天按的：跨过零点后偏移自动作废回到今天，不会闷头再往后顺延一天。夜里自动切到下一天时，也会跳过放假和没课的日子。

## 小组件在更多手机上找得到、装得上

- 选择器用的预览图从矢量换成位图。EMUI / 鸿蒙的小组件选择器按位图处理预览图，遇到矢量图会把整项直接过滤掉——「华为手机上根本找不到课简的小组件」多半是这个原因。
- 最小尺寸按华为桌面的格子公式（70×格数−30）重新声明，不会因为声明得太宽而被整格隐藏。
- 接上厂商自己的小组件刷新广播，加上后不会再卡在「加载中」。
- Android 12 及以上把课程行直接内联进小组件，启动器不必绑定后台服务也能画出列表。

另需注意：鸿蒙 NEXT（HarmonyOS 5）已移除安卓兼容层，安卓应用的小组件在该系统上不会出现，无法通过适配解决。帮助页内也已说明。

## 「一键添加」不再假装成功了

以前只要系统接下了添加请求就提示「已发起添加请求」，但小米、华为这些系统常常把弹窗悄悄拦掉，用户那边就是点了没反应。现在会盯着桌面上实际装上的数量：

- 真的加上了才提示成功；
- 十几秒还没动静，就直接告诉你没检测到成功，并给出手动添加步骤和「后台弹出界面」权限的入口；
- 请求会把厂商那一份 provider 也试一遍，补上 MIUI 老版本需要的快捷方式权限。

小组件面板右上角的帮助里新增「自检信息」：设备、系统（含鸿蒙 / EMUI 版本）、当前桌面、是否支持一键添加、每个小组件被系统解析到几个 provider、桌面上有几个、预览图是不是位图、有没有厂商自启动页，可一键复制。手机上找不到小组件时，对照这段能看出卡在哪一环。

同时修复：Android 11 起未声明包可见性会导致查不到当前桌面，厂商识别判断出错（原生机型上会把系统选择器当成桌面）。现已补上 `<queries>` 声明。

另外，非厂商机型上会把 MIUI / vivo 用的那份副本 receiver 收起来，小组件选择器里每个小组件只出现一次（之前是两次）。已经放在桌面上的副本不受影响。

## 小组件配色跟着应用主题走

以前换了应用主题色，小组件底色还是老样子。现在默认「跟随应用主题」，想让小组件单独一个颜色也仍然可以在设置里挑。

## 权限：没开就明确拦住，开了也能关掉

- **建提醒前先看权限**。通知或精确闹钟没给的时候，新建闹钟、新建规则、给课程加提醒都会先弹出说明，列出缺哪几项、每项为什么需要，点「去开启」直接进对应的系统页面；回来点「重新检查」会自动接着刚才那一步。缺的只是电池白名单这类不影响能不能响的项，则不再挡路。
- **省电优化点了没反应修好了**。已经在白名单里时，系统会把「请求加入白名单」这条请求直接吃掉，界面上什么都不出现，也就没法取消授权。现在已授权时改为打开系统的白名单总列表，可以在那里关掉。
- 权限页上每一项都改成候选入口逐个回退，最后兜底到应用详情页，点了一定有反应；一条都打不开时会明确提示手动路径，而不是静默失败。
- 国产系统上新增「自启动 / 后台管理」「后台弹出界面」两项入口（小米、华为、荣耀、OPPO、vivo、一加、三星、魅族的安全中心页面），这两项系统不提供查询接口，徽章显示「需手动确认」。

## 课表与提醒界面的几处排版

- 调休那天表头里的「按 10/5」不再被截掉半个字，表头高度跟着字号和系统字体缩放一起长。
- 新建提醒规则时，「存在」「提醒」这类选项在窄屏或大字号下被挤成两列的问题修好了，放不下就改成上下两段。
- 课程详情页在这门课已经有提醒时，按钮变成「取消提醒」，不再永远只有「提醒」一个方向。

## 日期选择器的星期表头不再全是「星」

新建闹钟、临时调课、节假日这几处的日期选择器，星期表头七列显示的都是「星」，看不出是周几。

原因不在应用里：Material3 的 DatePicker 用系统的「单字星期名」生成表头，而中文环境下这个值会退化成「星期X」的第一个字，于是七列一模一样，而 DatePicker 没有任何参数能改这一行。开学日期那里早就换成了自绘月历，这次把剩下三处也一并换掉，表头用应用自己的单字星期文案（一二三四五六日），并跟课表一样支持周一/周日起始。

## 工程侧

- CI 以前只跑 `core-kernel` 一个模块的单测，其余模块的用例等于没跑；现在跑全量，并加了 Android Lint 关卡（当前 0 个 error，失败时会把报告传成产物）。
- Lint 揪出闹钟守护服务的一个真问题：`specialUse` 这个前台服务类型是 Android 14 才有的，在更早的系统上传它会被系统拒掉，服务进不了前台、接着被判超时杀掉。已按版本分支处理。
- 清掉三条没人引用的文案、把「…」统一成省略号字符、修掉两处 Compose 状态装箱。

## 闹钟自检

「闹钟没响」背后至少有六种原因：权限被收走、通知渠道被单独关掉、系统进了省电、排程没登记上、送到了被去重吃掉、进程被厂商清理器杀掉。表面现象都一样，逐个排查很费劲。

设置 → 权限里新增「闹钟自检」，一次把判断依据摊开：通知总开关、**响铃渠道有没有被单独关掉**（这条最难猜，权限全绿也能哑）、精确闹钟、全屏通知、电池优化、省电模式、勿扰、厂商自启动页、常驻守护（开没开 / 现在还在不在跑）、已登记闹钟（记录 N 条 vs 系统里实际还剩 M 条，对不上就是排程掉了）、下一次提醒、最近 5 次响铃流水（响了 / 错过）。可一键复制。

## 课表导入前先看变化

教务系统改了课，以前只会提示「同步成功」，到底动了哪几门全靠自己翻，而且新表直接把旧表盖掉。

现在同步回来如果有增减，会先弹出对比：新增哪几门、减少哪几门，各自的星期节次地点，超过 5 门折叠起来。然后两个出口——**覆盖当前课表**，或者**新建一个课表**（建完自动切过去，原来那份留在旧学期里，右上角加号能切回）。没有旧表或者内容没变就照旧直接写，不多这一步。

比对不按课程 id：教务系统每次抓取都换一串 id，按 id 比会把整张表判成全删全增。改成按「课名 + 星期 + 节次 + 周次 + 地点」比，换了教室会如实显示成一增一删。

扫码 / 分享码导入的确认框也加了「导入到新课表」，并且**默认开启**——导入别人的课表多半不是要替掉自己这份。

## 周次可以自选，也可以自己加空白周

- 课程编辑里的周次多了**自选**一档：点开是整学期的周次矩阵，一周周点选，确认后起止周输入框收起，只留一行「已选 5 周 / 3、5、7、11、13」，右侧常驻「修改」。切回全部周 / 单周 / 双周，输入框就回来。
- 同时修复：判断已有周次属于哪一档，过去是「全是奇数就算单周」，3、5、11 这类不规则周次会被归入「全部周」，**打开编辑器即被区间改写成 3 到 11 的每一周**，保存后凭空多出数周。现改为判断「能否用区间加单双周表达」，表达不出即为自选。
- 周课表**翻到最后一页是一个大加号**，点一下往后接一周空白课表；点最上方的周次，网格末尾也有一格加号。加出来的空白周**长按可以删**，但要把「确认」两个字打出来删除按钮才会亮。课程推导出来的那些周不能删——那条范围是从课程周次算出来的，删了下次还会回来。

## 调休那天会标出来

周末被调成上课日时，课表表头会用红色标一个「调休」。日历上看着是休息日，不标很容易睡过去。空白格子**双击**现在也能打开当天的放假 / 调休设置（原来只有双击日期栏能开，那一条太窄）。

## 背景设置重做

- 改成**两栏**：课表背景 / 小组件背景。小组件背景现在和课表对等——**能裁剪**（按挂件比例取景，原来直接把原图塞进去，竖图铺上去只剩中间一条）、**能调透明度**、有自己的实时预览。
- 效果预览不再是一个孤零零的方块，改成真实结构的缩略课表：星期表头、节数栏、错落分布的课程格，圆角和透明度都取你当前的设置，铺上背景图能真看出字还读不读得清。
- 透明度从加减号改成**滑块**。
- 「与表头背景一致」改名「恢复默认」并挪到最下面，而且名副其实了：会把背景图、自定颜色、透明度一并清掉（原来只切一下类型，图和颜色都还留着）。
- 背景图片挪到第一位。
- **修了裁剪只能左右拖的 bug**：手势闭包一直抱着第一帧算出来的可移动余量，而第一帧还没缩放，窄的那个方向余量正好是 0，于是放大之后那个方向怎么拖都不动。

## 小组件

- **跨过零点会自己回到今天**。以前换天这一刻没有任何刷新，早上起来看到的还是昨天那一页；翻页偏移在锚点缺失时还会被续命一天，于是顺延成了明天。现在零点固定排一次刷新，偏移只认「今天按出来的」，其余一律回到当天。
- **选择器里的预览图重画了**。原来是几根灰条，看着像半成品草图，和装上之后完全不像。现在按真实样子画：日期、翻页键、课程行的时间课名地点，配色取默认主题，简中 / 英文 / 繁中各一套。
- **一键添加落空会自动换一种方式再试**。`requestPinAppWidget` 返回 true 只表示请求被受理，不表示弹窗会出现——vivo 桌面认的是带它自家元数据的那份 provider，拿通用那份去请求它照样回 true 然后悄悄丢掉。现在厂商机型上先请求厂商副本，落空了自动换下一个再来一次，两条都不行才提示手动。
- vivo 的添加指引改成实情：上面那栏「原子组件」是 vivo 自家的体系，第三方应用不在里面，要滑到底点「应用挂件」。

## 界面语言

生产代码里的中文硬编码从 282 处降到 186 处，砍掉的都是你真能看到的：闹钟自检页、小组件自检页、系统文件选择器里的根目录名、导出的 .ics 日历内容、扫码失败提示、备份恢复失败、安装器提示、日志与元数据的分享标题、下载源名称、小组件预览里的示例文案（三种语言各一套图）。

剩下的 186 处是刻意保留的：给模型的 AI 提示词、节假日数据集的中文键、闹钟去重用的语言无关稳定键、提醒规则的持久化前缀、预览假数据、中文地点解析关键词、只进日志的文本，以及语言选单里的「繁體中文」。

英文的复数也修了：54 条会随数量变形的文案改成了标准复数表，不会再出现「1 courses」。

**修了一个切换语言就弹旧提示的 bug**：切语言会重建界面但 ViewModel 还活着，「这条提示已经弹过了」的记录被清空，于是上一次的提示又弹一遍。另外「暂无可立即添加的闹钟」这句在一条提醒都没建过时不再出现。
