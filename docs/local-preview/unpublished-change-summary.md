# 0.7.5 发布前改动梳理

审阅日期：2026-10-04。基准提交：`1fadb78`，审阅时版本配置为 0.7.4，发布时调整为 0.7.5（测试版、版本代码 31）。本地 `main` 相对已有 `origin/main` 跟踪记录没有领先提交，本次内容来自工作区未提交的改动和新增文件。

面向用户的图文稿在 `app/src/debug/assets/release-preview/next-local.md`。Debug 包附带该稿及截图，高级工具的「预览本地更新公告」可直接离线读取；私有 `release-preview` 目录中的自定义稿仍优先。素材不进入 Release 包。

## 主要新增功能

- 今日课程概览与全天课程时间线：当前／下一节课程、上下课倒计时、课程进度、冲突明细；仅在今天的日视图出现，设置中可关闭。
- 课程日历小组件：周课表／月历、翻页与回到当前日期、日期深链，包含课程、考试、事务与休／班标记。
- 待完成小组件与组件内容联动：开始／截止时间、紧急状态、进入来源组件；仅有启用中的扩展组件时开放。
- 插件与组件多来源市场：各自默认公有仓库、添加额外仓库、连通检测、独立错误、去重、来源名称、移除确认。
- GitHub 令牌登录与私有仓库读取：账号校验、Keystore 加密、排除备份、退出／换账号清理私有缓存，私有附件直接经 API 下载。
- 备忘录全文搜索：跨笔记本标题、全文与课程检索，包括已完成笔记，清空恢复原筛选。
- 手动导出明天闹钟到系统时钟、相同分钟合并、时间限制提示、静音和取消静音。
- 扩展组件运行、后台同步、新内容及截止提醒、登录失效提示、课表事务与内容详情联动。

## 主要前端调整

- 插件／组件目录区分已安装和市场，直接搜索；详情隐藏分类切换，简介与仓库信息独立成卡片。
- 安装预检以简介、来源、真实包大小为主，权限及校验默认折叠，窗口固定、内部滚动，达到 5 MiB 时显示真实下载进度。
- 新闹钟响铃页：大时钟、日期、主题配色、滑动关闭与延后入口。
- 搜索框、顶部图标按钮、信息块和删除确认框抽成共用控件；备忘录顶部统计缩为紧凑横排。
- 新小组件分组、图标箭头、长正文滚动、系统栏明暗适配。
- 无课／假日／下课／空任务状态加入每日稳定的情境提示，支持简中、繁中、英文。

## 主要修复

- 闹钟滑到底无法关闭；假日跳过与单闹钟例外、静音日期和预告的一致性。
- 小组件在课程编辑、删除后的重复与旧内容回流。
- 移入课程绕过假日／静音策略、跨周调课地点错误。
- 组件内部滑动误触侧边栏、长正文滚动受影响。
- 来源或账号切换后的迟到请求及私有缓存；刷新／安装沿用旧版本信息。

## 雨课堂组件的独立状态

相邻 `YuKeTang_notice_plugin` 本地源码与重打包 ZIP 为 v1.2.0、接口版本 4，包含自带登录、设置、月历、列表、往期公告、正文与附件管理。48 项组件测试与实际宿主页面检查通过。本地包需独立导入，不宣称公有市场已发布 v1.2.0；此前核对的公有 Release 仍是 v1.0.0。

## 发布前需保留的边界

- 默认 GitHub 登录为细粒度令牌。设备码登录只有可选实现，未配置 OAuth Client ID 的默认包不展示网页授权。
- 系统时钟只接收创建请求，需到时钟应用核对；写入后不会自动跟随调课或假日变化。
- 通知、横幅、锁屏与后台同步受手机权限和系统调度影响，不承诺所有手机完全相同。
- 审阅发现上课通知的「延后 10 分钟」入口与“本节已经提醒”去重逻辑可能冲突：留作后续专项验证，不作为已完成的新功能写入公告。
- 课程备忘录本身、课表事务本身、双指缩放、设置搜索、常用项和调色盘已在 0.7.4 中实现，本次公告只写它们的新改进。
